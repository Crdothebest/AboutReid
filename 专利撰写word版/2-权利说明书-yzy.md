一种基于多尺度滑动窗口和专家网络的特征融合方法

技术领域
[0001] 本发明属于计算机视觉与深度学习技术领域，具体涉及一种基于多尺度滑动窗口与专家网络的特征融合方法。该方法适用于跨模态行人重识别、多尺度目标检测及复杂场景下的视觉特征融合任务。

背景技术
[0002] 随着深度学习技术在计算机视觉领域的快速发展，特征融合已成为提升模型识别能力和泛化性能的关键技术之一。通过多尺度特征提取与智能融合机制，可以有效增强视觉特征的表达能力，从而提高系统在目标识别、特征匹配及图像检索等任务中的精度与效率。近年来，随着卷积神经网络、Transformer等深度学习架构的广泛应用，多尺度特征融合技术在目标检测、图像分割、行人重识别等视觉任务中取得了显著进展，已成为现代计算机视觉系统的核心组件。
[0003] 然而，现有特征融合方法在应对复杂视觉场景时仍存在诸多不足。传统多尺度特征融合方法多采用固定尺度的卷积核或预定义的特征金字塔结构进行特征提取，如FPN（Feature Pyramid Network）和PANet等方法，这些方法通常基于固定的融合策略，无法根据输入特征的语义分布和上下文信息动态调整融合权重，导致模型在面对不同尺度的目标或复杂背景时，特征表达能力受限。此外，现有方法在处理多尺度特征时，往往采用简单的拼接、逐元素相加或加权平均等操作，缺乏对不同尺度特征的差异化建模能力，难以充分挖掘局部细节特征、中层结构特征及全局上下文特征之间的互补关系。
[0004] 为了提升多尺度特征融合的效果，研究人员提出了基于注意力机制、门控机制等自适应融合策略。然而，这些方法在多尺度特征处理过程中易产生特征干扰，不同尺度间的信息相互影响，削弱了融合后的判别性能。多数方法仅采用统一的融合方式处理不同尺度的特征，缺乏针对不同尺度特征的专业化建模，在同时处理局部细节特征、中层结构特征及全局上下文特征时，容易造成特征冗余与语义模糊，从而降低模型在复杂任务中的识别精度与泛化能力。特别是在跨模态行人重识别等需要精确特征匹配的任务中，现有方法的特征表达能力难以满足实际应用需求。
[0005] 本发明针对现有特征融合方法存在的问题，提供一种基于多尺度滑动窗口与专家网络的特征融合方法，通过引入多尺度滑动窗口机制实现层次化特征提取，结合混合专家网络（Mixture-of-Experts, MoE）架构实现不同尺度特征的专业化处理，并利用门控网络实现自适应融合权重分配，既能有效提升多尺度特征的表达能力，又能减少特征干扰和冗余，从而在提高模型识别精度的同时兼顾计算效率和泛化性能，具有广泛的实际应用价值。

发明内容
[0006] 本发明的目的在于提出一种基于多尺度滑动窗口与专家网络的特征融合方法，以克服现有特征融合方法中存在的若干不足，包括但不限于多尺度处理能力不足、融合策略单一、特征干扰严重，以及对复杂视觉场景适应性差的问题。
[0007] 本方法以多尺度滑动窗口和混合专家网络为核心，通过对输入特征进行多尺度划分和专业化处理，使不同尺度的特征能够被针对性地建模和融合，进而提升特征表达的判别性和泛化性。在实际特征融合过程中，通过门控网络动态调整各尺度特征的融合权重，兼顾特征表达能力和计算效率，对外表现近似于经过优化的统一特征表示。最终实现的一体化融合方案，不仅强化了多尺度特征的表达能力，还具备良好的可扩展性和对复杂视觉场景的适应性，适合实际部署于行人重识别、目标检测等计算机视觉任务中。
[0008] 本发明为实现上述目标提供如下的技术方案：此基于多尺度滑动窗口与专家网络的特征融合方法主要包括五个步骤：多尺度特征提取、特征编码与归一化、专家网络专业化处理、门控网络动态决策和加权融合。

技术方案
[0009] 1.多尺度特征提取：对输入的视觉特征序列采用多尺度滑动窗口进行划分，所述滑动窗口包括4×4、8×8、16×16等不同尺度，用以从输入特征图中提取具有不同感受野范围的局部特征子集，从而获得多尺度特征表示。本方法通过设置不同大小的滑动窗口，能够从同一输入特征图中捕获不同尺度的空间信息，其中较小尺度的窗口（如4×4）专注于局部细节特征，较大尺度的窗口（如16×16）则捕获更广泛的上下文信息，从而形成层次化的多尺度特征表示。

设输入特征图为X∈R^H×W×C，其中H、W、C分别表示特征图的高度、宽度和通道数。对于尺度为s×s的滑动窗口，采用步长为stride的滑动方式，将输入特征图划分为多个重叠或非重叠的特征子区域。对于第k个尺度（k=1,2,…,K），其滑动窗口大小为s_k×s_k，则提取的多尺度特征子集可表示为：
{F_k^(i,j)} = {X[i:i+s_k, j:j+s_k, :] | i=0,stride,2×stride,…,H-s_k; j=0,stride,2×stride,…,W-s_k}
其中，F_k^(i,j)∈R^(s_k×s_k×C)表示第k个尺度下位置(i,j)处的特征子集，K为预设的尺度总数。通过多尺度滑动窗口机制，从同一输入特征图中提取得到K组不同尺度的特征子集，每组特征子集包含N_k个特征块，其中N_k取决于滑动窗口的步长和特征图尺寸。
[0010] 2.特征编码与归一化：将各尺度提取的特征子集进行统一编码和归一化处理，以保证不同尺度特征在空间维度和数值分布上的一致性，为后续融合提供基础。具体地，对每个尺度的特征子集进行维度对齐和数值归一化，使得不同尺度的特征能够在相同的特征空间中进行比较和融合，避免因尺度差异导致的特征分布不匹配问题。

对于第k个尺度提取的特征子集F_k^(i,j)∈R^(s_k×s_k×C)，首先通过空间池化操作（如全局平均池化或最大池化）将其压缩为固定维度的特征向量，然后通过线性变换层进行维度对齐。具体地，特征编码过程可表示为：
f_k^(i,j) = Flatten(Pool(F_k^(i,j))) ∈ R^d
其中，Pool(·)表示池化操作，Flatten(·)表示展平操作，d为统一的目标特征维度。随后，对编码后的特征进行层归一化（Layer Normalization）处理，以稳定训练过程并加速收敛：
f̃_k^(i,j) = LN(f_k^(i,j)) = γ · (f_k^(i,j) - μ) / (σ + ε) + β
其中，μ和σ分别为特征f_k^(i,j)的均值和标准差，γ和β为可学习的缩放和偏移参数，ε为数值稳定性常数（通常取10^-5）。经过编码和归一化后，所有尺度的特征均被映射到统一的d维特征空间，便于后续的专家网络处理和融合操作。
[0011] 3.专家网络专业化处理：基于混合专家机制（Mixture-of-Experts, MoE）构建多个具有差异化参数配置的专家子网络，并将不同尺度特征分别输入对应专家网络中进行处理。该模块能够实现针对不同尺度特征的专业化建模，增强特征表示的判别性和泛化性，同时降低尺度间的特征干扰。每个专家网络专门负责处理特定尺度的特征，通过独立的参数学习和特征变换，使得不同尺度的特征能够被充分挖掘和优化，从而提升整体特征的表达能力。

本方法构建K个专家网络{E_1, E_2, …, E_K}，每个专家网络E_k专门处理第k个尺度的特征。每个专家网络E_k由多层全连接网络或卷积网络组成，其结构可表示为：
E_k(f̃_k) = W_k^(L) · ReLU(W_k^(L-1) · … · ReLU(W_k^(1) · f̃_k + b_k^(1)) … + b_k^(L-1)) + b_k^(L)
其中，W_k^(l)和b_k^(l)分别表示第k个专家网络第l层的权重矩阵和偏置向量，L为网络层数，ReLU(·)为激活函数。对于归一化后的特征f̃_k^(i,j)，经过对应专家网络E_k处理后，得到专业化特征表示：
h_k^(i,j) = E_k(f̃_k^(i,j)) ∈ R^d'
其中，d'为专家网络输出的特征维度。通过为不同尺度特征分配专门的专家网络，使得每个专家网络能够学习到针对特定尺度特征的优化变换，从而提升特征表示的判别性和泛化性。对于第k个尺度的所有特征块，经过专家网络处理后得到该尺度的特征集合{H_k} = {h_k^(i,j) | ∀(i,j)}。
[0012] 4.门控网络动态决策：通过门控网络对各专家网络的输出结果进行动态权重分配。所述门控网络根据输入特征的语义分布、上下文信息及任务需求，确定不同尺度特征在最终融合结果中的贡献度，实现自适应的特征融合。门控网络通过学习不同尺度特征的重要性，动态调整各专家网络输出的权重，使得融合过程能够根据输入特征的特点自适应地选择最相关的尺度信息，从而提升融合效果。

门控网络G(·)以输入特征X或全局上下文信息作为输入，输出各专家网络的融合权重。具体地，门控网络首先对输入进行特征提取和压缩，然后通过Softmax函数生成归一化的权重分布：
g = G(X) = [g_1, g_2, …, g_K]^T
其中，g_k表示第k个专家网络的权重，满足Σ_(k=1)^K g_k = 1且g_k ≥ 0。门控网络的具体计算过程可表示为：
g = Softmax(W_g · Pool(X) + b_g)
其中，W_g和b_g分别为门控网络的权重矩阵和偏置向量，Pool(·)表示全局池化操作。对于每个尺度的专家网络输出H_k，门控网络为其分配权重g_k，从而实现对不同尺度特征的自适应加权。权重g_k反映了第k个尺度特征在当前输入下的重要性，使得融合过程能够根据输入特征的特点动态调整各尺度的贡献度。
[0013] 5.加权融合：将经门控网络加权后的多尺度专家特征进行融合，生成层次化、稳健的全局特征表示。所述融合可采用基于加权求和或多头注意力机制的策略，以进一步增强多尺度特征间的互补性。通过加权融合，不同尺度的特征能够以最优的方式组合，形成既包含局部细节又包含全局上下文的统一特征表示，从而提升模型在复杂视觉任务中的性能。

对于加权求和策略，将各尺度专家网络输出的特征按照门控网络分配的权重进行加权求和，得到最终的融合特征：
F_fused = Σ_(k=1)^K g_k · H̄_k
其中，H̄_k表示第k个尺度所有特征块的平均池化或最大池化结果，即H̄_k = Pool({h_k^(i,j) | ∀(i,j)})。对于多头注意力机制策略，首先将各尺度的特征H_k作为查询（Query）、键（Key）和值（Value），然后通过多头注意力计算不同尺度特征间的交互关系：
F_fused = MultiHeadAttention(Q, K, V) = Concat(head_1, …, head_h) · W^O
其中，Q = [H̄_1, …, H̄_K]，K = [H̄_1, …, H̄_K]，V = [H̄_1, …, H̄_K]，h为注意力头数，每个注意力头head_i的计算为：
head_i = Attention(Q · W_i^Q, K · W_i^K, V · W_i^V) = Softmax((Q · W_i^Q)(K · W_i^K)^T / √d_k) · (V · W_i^V)
其中，W_i^Q、W_i^K、W_i^V和W^O为可学习的权重矩阵，d_k为键的维度。通过加权融合，不同尺度的特征能够以最优的方式组合，形成既包含局部细节又包含全局上下文的统一特征表示F_fused，从而提升模型在复杂视觉任务中的性能。

有益效果
[0014] 本发明提出了一种基于多尺度滑动窗口与专家网络的特征融合方法，通过引入多尺度滑动窗口机制和混合专家网络架构，能够有效实现不同尺度特征的层次化建模和专业化处理，显著提升特征表达的判别性和泛化性。相较于现有技术，该方法在保障特征表达能力的同时，兼顾计算效率和模型复杂度，通过门控网络实现的自适应融合策略，实现了对多尺度特征的高效利用。系统具备良好的自适应性和可扩展性，且计算开销可控，能够动态响应不同视觉任务的需求，具有良好的可部署性和扩展性，适用于实际部署于包括行人重识别、目标检测在内的计算机视觉场景。

具体实施方式
[0018] 以下将结合说明书附图对本发明做进一步描述。
[0019] 如图1所示，基于多尺度滑动窗口与专家网络的特征融合方法主要包括五个步骤：多尺度特征提取、特征编码与归一化、专家网络专业化处理、门控网络动态决策和加权融合。
[0020] 在具体实施时，首先，多尺度特征提取模块对输入的视觉特征图采用不同尺度的滑动窗口进行划分，提取具有不同感受野范围的局部特征子集，从而获得层次化的多尺度特征表示；其次，特征编码与归一化模块对各尺度提取的特征子集进行统一编码和归一化处理，通过空间池化和线性变换实现维度对齐，并通过层归一化稳定特征分布，为后续融合提供基础；然后，专家网络专业化处理模块基于混合专家机制构建多个具有差异化参数配置的专家子网络，将不同尺度特征分别输入对应专家网络中进行专业化建模，增强特征表示的判别性和泛化性；接着，门控网络动态决策模块根据输入特征的语义分布和上下文信息，通过Softmax函数生成归一化的权重分布，动态调整各专家网络输出的融合权重；最后，加权融合模块将经门控网络加权后的多尺度专家特征进行融合，可采用基于加权求和或多头注意力机制的策略，生成层次化、稳健的全局特征表示，从而提升模型在复杂视觉任务中的性能。
[0021] 本发明的实施例如下：
[0022] 步骤1 多尺度特征提取：
[0023] 对于输入的视觉特征图X∈R^H×W×C，其中H=64、W=32、C=2048分别表示特征图的高度、宽度和通道数，本实施例设置K=3个不同尺度的滑动窗口，分别为s_1=4、s_2=8、s_3=16，对应4×4、8×8、16×16的窗口大小。滑动窗口的步长stride设置为2，采用重叠滑动方式以增加特征覆盖范围。对于第k个尺度（k=1,2,3），其滑动窗口大小为s_k×s_k，则提取的多尺度特征子集可表示为：
{F_k^(i,j)} = {X[i:i+s_k, j:j+s_k, :] | i=0,2,4,…,H-s_k; j=0,2,4,…,W-s_k}
其中，F_k^(i,j)∈R^(s_k×s_k×C)表示第k个尺度下位置(i,j)处的特征子集。通过多尺度滑动窗口机制，从同一输入特征图中提取得到3组不同尺度的特征子集，第1个尺度（4×4）提取得到约480个特征块，第2个尺度（8×8）提取得到约112个特征块，第3个尺度（16×16）提取得到约24个特征块，从而形成层次化的多尺度特征表示。
[0024] 步骤2 特征编码与归一化：
[0025] 对于第k个尺度提取的特征子集F_k^(i,j)∈R^(s_k×s_k×C)，首先通过全局平均池化操作将其压缩为固定维度的特征向量，然后通过线性变换层进行维度对齐。具体地，特征编码过程可表示为：
f_k^(i,j) = W_enc · Flatten(GAP(F_k^(i,j))) ∈ R^d
其中，GAP(·)表示全局平均池化操作，Flatten(·)表示展平操作，W_enc∈R^(d×C)为可学习的线性变换矩阵，d=512为统一的目标特征维度。随后，对编码后的特征进行层归一化（Layer Normalization）处理，以稳定训练过程并加速收敛：
f̃_k^(i,j) = LN(f_k^(i,j)) = γ · (f_k^(i,j) - μ) / (σ + ε) + β
其中，μ和σ分别为特征f_k^(i,j)的均值和标准差，γ和β为可学习的缩放和偏移参数，ε=10^-5为数值稳定性常数。经过编码和归一化后，所有尺度的特征均被映射到统一的512维特征空间，便于后续的专家网络处理和融合操作。
[0026] 步骤3 专家网络专业化处理：
[0027] 本实施例构建K=3个专家网络{E_1, E_2, E_3}，每个专家网络E_k专门处理第k个尺度的特征。每个专家网络E_k由3层全连接网络组成，其结构可表示为：
E_k(f̃_k) = W_k^(3) · ReLU(W_k^(2) · ReLU(W_k^(1) · f̃_k + b_k^(1)) + b_k^(2)) + b_k^(3)
其中，W_k^(1)∈R^(512×1024)、W_k^(2)∈R^(1024×512)、W_k^(3)∈R^(512×256)分别表示第k个专家网络各层的权重矩阵，b_k^(l)为对应层的偏置向量，ReLU(·)为激活函数。对于归一化后的特征f̃_k^(i,j)∈R^512，经过对应专家网络E_k处理后，得到专业化特征表示：
h_k^(i,j) = E_k(f̃_k^(i,j)) ∈ R^256
其中，256为专家网络输出的特征维度。通过为不同尺度特征分配专门的专家网络，使得每个专家网络能够学习到针对特定尺度特征的优化变换，从而提升特征表示的判别性和泛化性。对于第k个尺度的所有特征块，经过专家网络处理后得到该尺度的特征集合{H_k} = {h_k^(i,j) | ∀(i,j)}。
[0028] 步骤4 门控网络动态决策：
[0029] 门控网络G(·)以输入特征图X的全局上下文信息作为输入，输出各专家网络的融合权重。具体地，门控网络首先对输入进行全局平均池化和特征提取，然后通过Softmax函数生成归一化的权重分布：
g = G(X) = Softmax(W_g · GAP(X) + b_g) = [g_1, g_2, g_3]^T
其中，W_g∈R^(3×2048)和b_g∈R^3分别为门控网络的权重矩阵和偏置向量，GAP(·)表示全局平均池化操作，g_k表示第k个专家网络的权重，满足g_1 + g_2 + g_3 = 1且g_k ≥ 0。对于每个尺度的专家网络输出H_k，门控网络为其分配权重g_k，从而实现对不同尺度特征的自适应加权。权重g_k反映了第k个尺度特征在当前输入下的重要性，使得融合过程能够根据输入特征的特点动态调整各尺度的贡献度。例如，当输入图像包含大量细节信息时，门控网络可能为较小尺度（4×4）的专家网络分配更高的权重；当输入图像包含较大目标或全局结构时，门控网络可能为较大尺度（16×16）的专家网络分配更高的权重。
[0030] 步骤5 加权融合：
[0031] 本实施例采用基于加权求和的融合策略，将各尺度专家网络输出的特征按照门控网络分配的权重进行加权求和，得到最终的融合特征：
F_fused = Σ_(k=1)^3 g_k · H̄_k
其中，H̄_k表示第k个尺度所有特征块的平均池化结果，即H̄_k = (1/N_k) · Σ_(i,j) h_k^(i,j)，N_k为第k个尺度的特征块数量。通过加权融合，不同尺度的特征能够以最优的方式组合，形成既包含局部细节又包含全局上下文的统一特征表示F_fused∈R^256，从而提升模型在复杂视觉任务中的性能。
[0032] 对于需要更高性能的场景，本实施例还可采用多头注意力机制策略进行融合。首先将各尺度的特征H̄_k作为查询（Query）、键（Key）和值（Value），然后通过多头注意力计算不同尺度特征间的交互关系：
F_fused = MultiHeadAttention(Q, K, V) = Concat(head_1, …, head_h) · W^O
其中，Q = [H̄_1, H̄_2, H̄_3]，K = [H̄_1, H̄_2, H̄_3]，V = [H̄_1, H̄_2, H̄_3]，h=8为注意力头数，每个注意力头head_i的计算为：
head_i = Attention(Q · W_i^Q, K · W_i^K, V · W_i^V) = Softmax((Q · W_i^Q)(K · W_i^K)^T / √d_k) · (V · W_i^V)
其中，W_i^Q、W_i^K、W_i^V∈R^(256×32)和W^O∈R^(256×256)为可学习的权重矩阵，d_k=32为键的维度。通过多头注意力机制，不同尺度的特征能够进行更深入的交互和融合，进一步提升特征表达的判别性和泛化性。
[0033] 步骤6 模型训练与优化：
[0034] 在模型训练过程中，将融合后的特征F_fused输入到下游任务网络（如分类器、检索网络等）中进行端到端训练。损失函数根据具体任务进行设计，例如在行人重识别任务中，可采用三元组损失（Triplet Loss）和交叉熵损失的组合：
ℒ = ℒ_triplet + λ_ce · ℒ_ce
其中，ℒ_triplet用于拉近同一身份样本的特征距离，推远不同身份样本的特征距离；ℒ_ce为分类损失，用于优化特征表示；λ_ce为平衡系数，通常设置为0.5。通过端到端的联合优化，多尺度滑动窗口、专家网络和门控网络能够协同工作，学习到最优的特征提取、专业化处理和融合策略，从而提升模型在跨模态行人重识别、目标检测等复杂视觉任务中的性能。
