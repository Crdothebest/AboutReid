# 三种拼接方式完整流程图

## 1. 无预处理

```
输入：原始多尺度特征
    [feat_4x4, feat_8x8, feat_16x16]
    每个特征形状: [B, 512]
    │
    ├─→ 直接进入 _expert_network_processing()
    │
    ├─→ 【专家网络处理阶段】
    │
    ├─→ 步骤1：拼接多尺度特征
    │       concat_features = torch.cat(multi_scale_features, dim=1)
    │       输出: [B, 1536]
    │       │
    │       └─→ 步骤2：门控网络计算专家权重
    │               expert_weights = self.gating_network(concat_features)
    │               输出: [B, 3] (如 [0.4, 0.3, 0.3])
    │               │
    │               └─→ 步骤3：专家网络处理各尺度特征
    │                       ├─ Expert_0(feat_4x4)  → output_0 [B, 512]
    │                       ├─ Expert_1(feat_8x8)  → output_1 [B, 512]
    │                       └─ Expert_2(feat_16x16) → output_2 [B, 512]
    │                       │
    │                       └─→ 步骤4：加权融合专家输出
    │                               weighted_outputs = []
    │                               for i, expert_output in enumerate(expert_outputs):
    │                                   weight = expert_weights[:, i]
    │                                   weighted_output = weight * expert_output
    │                                   weighted_outputs.append(weighted_output)
    │                               fused_feature = Σ(weighted_outputs)
    │                               输出: [B, 512]
    │                               │
    │                               └─→ 步骤5：最终融合层
    │                                       final_feature = self.final_fusion(fused_feature)
    │                                       输出: final_feature [B, 512]
```

## 2. 门控加权-预处理

```
输入：原始多尺度特征
    [feat_4x4, feat_8x8, feat_16x16]
    每个特征形状: [B, 512]
    │
    ├─→ 【门控加权-预处理阶段】
    │
    ├─→ 步骤1：拼接特征并计算门控权重
    │       concat_features = torch.cat(multi_scale_features, dim=1)
    │       输出: [B, 1536]
    │       │
    │       └─→ gate_weights = self.gate_network(concat_features)
    │               输出: [B, 3] (门控权重分布)
    │               │
    │               └─→ 步骤2：门控加权融合（对每个尺度特征）
    │                       for feat, weight in zip(multi_scale_features, gate_weights):
    │                           ├─ weighted_feat = feat * weight  # 门控加权
    │                           │   输出: [B, 512]
    │                           │
    │                           ├─ enhanced_feat = self.feature_enhancer(weighted_feat)
    │                           │   输出: [B, 512] (特征增强)
    │                           │
    │                           └─ enhanced_feat = enhanced_feat + feat * 0.3  # 残差连接
    │                               输出: [B, 512] (保留30%原始信息)
    │                               │
    │                               └─→ enhanced_multi_scale_features.append(enhanced_feat)
    │
    ├─→ 输出：增强后的多尺度特征
    │       [enhanced_feat_4x4, enhanced_feat_8x8, enhanced_feat_16x16]
    │       每个特征形状: [B, 512]
    │       │
    │       └─→ 进入 _expert_network_processing()
    │               │
    │               ├─→ 【专家网络处理阶段】
    │               │
    │               ├─→ 步骤1：拼接增强后的多尺度特征
    │               │       concat_features = torch.cat(enhanced_multi_scale_features, dim=1)
    │               │       输出: [B, 1536]
    │               │       │
    │               │       └─→ 步骤2：门控网络计算专家权重
    │               │               expert_weights = self.gating_network(concat_features)
    │               │               输出: [B, 3]
    │               │               │
    │               │               └─→ 步骤3：专家网络处理各尺度特征
    │               │                       ├─ Expert_0(enhanced_feat_4x4)  → output_0 [B, 512]
    │               │                       ├─ Expert_1(enhanced_feat_8x8)  → output_1 [B, 512]
    │               │                       └─ Expert_2(enhanced_feat_16x16) → output_2 [B, 512]
    │               │                       │
    │               │                       └─→ 步骤4：加权融合专家输出
    │               │                               weighted_outputs = []
    │               │                               for i, expert_output in enumerate(expert_outputs):
    │               │                                   weight = expert_weights[:, i]
    │               │                                   weighted_output = weight * expert_output
    │               │                                   weighted_outputs.append(weighted_output)
    │               │                               fused_feature = Σ(weighted_outputs)
    │               │                               输出: [B, 512]
    │               │                               │
    │               │                               └─→ 步骤5：最终融合层
    │               │                                       final_feature = self.final_fusion(fused_feature)
    │               │                                       输出: final_feature [B, 512]
```

## 3. 注意力-预处理

```
输入：原始多尺度特征
    [feat_4x4, feat_8x8, feat_16x16]
    每个特征形状: [B, 512]
    │
    ├─→ 【注意力-预处理阶段】
    │
    ├─→ 步骤1：构建注意力输入序列
    │       attention_input = torch.stack(multi_scale_features, dim=1)
    │       输出: [B, 3, 512] (序列格式)
    │       │
    │       └─→ 步骤2：多头注意力计算
    │               attn_output, attn_weights = self.multihead_attn(
    │                   attention_input, attention_input, attention_input
    │               )
    │               输出: 
    │               - attn_output: [B, 3, 512] (注意力处理后的特征)
    │               - attn_weights: [B, 3, 3] (注意力权重矩阵)
    │               │
    │               └─→ 步骤3：注意力加权融合（对每个尺度特征）
    │                       for original_feat, attn_feat in zip(multi_scale_features, attn_output):
    │                           ├─ weighted_feat = attn_feat  # 注意力加权
    │                           │   输出: [B, 512]
    │                           │
    │                           ├─ enhanced_feat = self.feature_enhancer(weighted_feat)
    │                           │   输出: [B, 512] (特征增强)
    │                           │
    │                           └─ enhanced_feat = enhanced_feat + original_feat * 0.3  # 残差连接
    │                               输出: [B, 512] (保留30%原始信息)
    │                               │
    │                               └─→ enhanced_multi_scale_features.append(enhanced_feat)
    │
    ├─→ 步骤4：全局注意力-预处理融合
    │       concat_features = torch.cat(enhanced_multi_scale_features, dim=1)
    │       输出: [B, 1536]
    │       │
    │       └─→ global_fusion = self.attention_fusion(concat_features)
    │               输出: [B, 512] (全局融合特征)
    │               │
    │               └─→ 将全局融合特征添加到每个尺度特征中
    │                       for i in range(len(enhanced_multi_scale_features)):
    │                           enhanced_multi_scale_features[i] = 
    │                               enhanced_multi_scale_features[i] + global_fusion * 0.2
    │                       输出: [B, 512] (每个尺度特征都融合了全局信息)
    │
    ├─→ 输出：增强后的多尺度特征
    │       [enhanced_feat_4x4, enhanced_feat_8x8, enhanced_feat_16x16]
    │       每个特征形状: [B, 512]
    │       │
    │       └─→ 进入 _expert_network_processing()
    │               │
    │               ├─→ 【专家网络处理阶段】
    │               │
    │               ├─→ 步骤1：拼接增强后的多尺度特征
    │               │       concat_features = torch.cat(enhanced_multi_scale_features, dim=1)
    │               │       输出: [B, 1536]
    │               │       │
    │               │       └─→ 步骤2：门控网络计算专家权重
    │               │               expert_weights = self.gating_network(concat_features)
    │               │               输出: [B, 3]
    │               │               │
    │               │               └─→ 步骤3：专家网络处理各尺度特征
    │               │                       ├─ Expert_0(enhanced_feat_4x4)  → output_0 [B, 512]
    │               │                       ├─ Expert_1(enhanced_feat_8x8)  → output_1 [B, 512]
    │               │                       └─ Expert_2(enhanced_feat_16x16) → output_2 [B, 512]
    │               │                       │
    │               │                       └─→ 步骤4：加权融合专家输出
    │               │                               weighted_outputs = []
    │               │                               for i, expert_output in enumerate(expert_outputs):
    │               │                                   weight = expert_weights[:, i]
    │               │                                   weighted_output = weight * expert_output
    │               │                                   weighted_outputs.append(weighted_output)
    │               │                               fused_feature = Σ(weighted_outputs)
    │               │                               输出: [B, 512]
    │               │                               │
    │               │                               └─→ 步骤5：最终融合层
    │               │                                       final_feature = self.final_fusion(fused_feature)
    │               │                                       输出: final_feature [B, 512]
```

## 三种方式的核心差异对比

### 预处理阶段差异

| 特性 | 无预处理 | 门控加权-预处理 | 注意力-预处理 |
|------|---------|---------|-----------|
| **预处理** | ❌ 无 | ✅ 门控加权 | ✅ 多头注意力 |
| **特征增强** | ❌ 无 | ✅ 有 | ✅ 有 |
| **关系建模** | ❌ 无 | ⚠️ 简单权重 | ✅ 全局注意力 |
| **残差连接** | ❌ 无 | ✅ 30%保留 | ✅ 30%保留 |
| **全局融合** | ❌ 无 | ❌ 无 | ✅ 有 |

### 专家网络处理阶段

| 特性 | 无预处理 | 门控加权-预处理 | 注意力-预处理 |
|------|---------|---------|-----------|
| **输入特征** | 原始特征 | 门控增强特征 | 注意力增强特征 |
| **处理流程** | ✅ 相同 | ✅ 相同 | ✅ 相同 |
| **专家网络** | ✅ 使用 | ✅ 使用 | ✅ 使用 |
| **门控网络** | ✅ 使用 | ✅ 使用 | ✅ 使用 |
| **最终融合** | ✅ 使用 | ✅ 使用 | ✅ 使用 |

## 总结

**共同点**：
- ✅ 三种方式**都会使用专家网络**
- ✅ 专家网络处理阶段的流程**完全相同**
- ✅ 最终都会输出 `[B, 512]` 的最终特征

**差异点**：
- 🔹 **无预处理**：无预处理，直接进入专家网络
- 🔹 **门控加权-预处理**：门控加权增强 → 专家网络
- 🔹 **注意力-预处理**：多头注意力增强 + 全局融合 → 专家网络

**选择建议**：
- 🚀 **快速实验**：无预处理
- ⚖️ **平衡性能**：门控加权-预处理
- 🎯 **追求精度**：注意力-预处理
