# MambaPro完整项目结构图

## 📊 从图像输入到最终输出的完整流程

```
================================================================================
                         MambaPro 完整项目结构流程图
================================================================================

┌─────────────────────────────────────────────────────────────────────────────┐
│                          阶段1: 图像输入与预处理                              │
└─────────────────────────────────────────────────────────────────────────────┘

【输入图像类别】
├─ RGBNT201 (三模态数据集)
│  ├─ RGB图像: 独立文件 [256×128×3]
│  ├─ NIR图像: 独立文件 [256×128×3]  
│  └─ TIR图像: 独立文件 [256×128×3]
│
├─ RGBNT100 (双模态数据集)
│  ├─ RGB图像: 单张图像左半部分 [width/2×height×3]
│  ├─ IR图像:  单张图像右半部分 [width/2×height×3]
│  └─ TI图像:  虚拟（使用IR副本）[width/2×height×3]
│
└─ MSVR310 (三模态拼接数据集)
   └─ 单张拼接图像: [768×128×3]
      ├─ RGB部分: [0:256, 0:128] → 裁剪
      ├─ NI部分:  [256:512, 0:128] → 裁剪
      └─ TI部分:  [512:768, 0:128] → 裁剪

【数据加载流程】
data/datasets/bases.py::read_image()
  ↓
输入: img_path(s) → 图像路径(单个或多个)
  ↓
处理:
  ├─ 单路径 → 切割成RGB/NI/TI (MSVR310)
  ├─ 多路径 → 分别读取 (RGBNT201)
  └─ 单路径重复 → 切割成RGB/IR/虚拟TI (RGBNT100)
  ↓
输出: [RGB图像, NI图像, TI图像] (PIL Image对象列表)

【图像预处理】
data/datasets/make_dataloader.py::train_transforms
  ↓
T.Compose([
  T.Resize([256, 128]),           # 调整尺寸
  T.RandomHorizontalFlip(p=0.5),  # 随机水平翻转
  T.Pad(10),                      # 填充
  T.RandomCrop([256, 128]),       # 随机裁剪
  T.ToTensor(),                   # 转为Tensor [0,1]
  T.Normalize([0.5,0.5,0.5], [0.5,0.5,0.5])  # 归一化到[-1,1]
])
  ↓
输出: [RGB_tensor, NI_tensor, TI_tensor]
     每个: [3, 256, 128] (C×H×W格式)

【Batch组织】
data/datasets/make_dataloader.py::train_collate_fn()
  ↓
输入: batch = [(img_list, pid, camid, viewid), ...]
  ↓
处理:
  ├─ 提取RGB: RGB_list = [img[0] for img in imgs]
  ├─ 提取NI:  NI_list = [img[1] for img in imgs]
  └─ 提取TI:  TI_list = [img[2] for img in imgs]
  ↓
堆叠:
  ├─ RGB = torch.stack(RGB_list) → [B, 3, 256, 128]
  ├─ NI  = torch.stack(NI_list)  → [B, 3, 256, 128]
  └─ TI  = torch.stack(TI_list)   → [B, 3, 256, 128]
  ↓
输出: {
      'RGB': [B, 3, 256, 128],
      'NI':  [B, 3, 256, 128],
      'TI':  [B, 3, 256, 128]
     }
     + pids, camids, viewids


┌─────────────────────────────────────────────────────────────────────────────┐
│                          阶段2: 模型前向传播                                  │
└─────────────────────────────────────────────────────────────────────────────┘

【MambaPro主模型】
modeling/make_model.py::MambaPro.forward()
  ↓
输入: x = {'RGB': [B,3,256,128], 'NI': [B,3,256,128], 'TI': [B,3,256,128]}
     + label, cam_label, view_label
  ↓
┌─────────────────────────────────────────────────────────────────────────────┐
│                    三种模态并行处理 (build_transformer)                       │
└─────────────────────────────────────────────────────────────────────────────┘

【RGB模态处理路径】
RGB [B, 3, 256, 128]
  ↓
build_transformer.forward(RGB, modality='rgb')
  ↓
┌─ CLIP视觉编码器 (self.base)
│  ├─ Patch划分: 256×128 → 16×8 = 128个patches
│  ├─ Patch Embedding: 每个patch → 512维向量
│  ├─ CLS Token: [B, 1, 512]
│  ├─ Position Embedding: 位置编码
│  ├─ SIE Embedding: 相机嵌入 (可选)
│  └─ Transformer编码: 12层Transformer块
│     ↓
│  输出: x = [CLS_token, patch_1, ..., patch_128]
│       形状: [B, 129, 512]
│
├─ 多尺度滑动窗口处理 (可选)
│  ├─ 分离: cls_token [B, 1, 512], patch_tokens [B, 128, 512]
│  │
│  ├─ 多尺度特征提取
│  │  ├─ 4×4窗口: Conv1d(k=4, s=4) → [B, 512, 32] → GAP → [B, 512]
│  │  ├─ 8×8窗口: Conv1d(k=8, s=8) → [B, 512, 16] → GAP → [B, 512]
│  │  └─ 16×16窗口: Conv1d(k=16, s=16) → [B, 512, 8] → GAP → [B, 512]
│  │
│  ├─ 特征拼接: [B, 1536] = [B, 512×3]
│  │
│  ├─ MLP融合 (传统方式)
│  │  └─ Linear(1536→512) + ReLU + Dropout + Linear(512→512)
│  │     → [B, 512]
│  │
│  └─ 或 MoE融合 (专家网络方式)
│     ├─ 门控网络初始化 (可选)
│     │  ├─ 初始权重设置: MOE_INIT_WEIGHTS (如 [0.35, 0.3, 0.35])
│     │  ├─ 通过偏置引导: log(weights) → gate_output.bias
│     │  └─ 使得初始权重分布接近期望值
│     ├─ 门控网络: 计算专家权重 [B, 3]
│     │  ├─ 输入: [B, 1536] (多尺度特征拼接)
│     │  ├─ MLP处理 → Temperature缩放 → Softmax
│     │  └─ 输出: [B, 3] (专家权重分布)
│     ├─ 专家网络处理:
│     │  ├─ Expert1(4×4特征) → [B, 512]
│     │  ├─ Expert2(8×8特征) → [B, 512]
│     │  └─ Expert3(16×16特征) → [B, 512]
│     ├─ 加权融合: Σ(weight_i × expert_output_i) → [B, 512]
│     └─ 最终融合层: Linear + LayerNorm → [B, 512]
│
└─ CLS Token增强
   ├─ enhanced_cls = cls_token + multi_scale_feature.unsqueeze(1)
   └─ 重新组合: x = [enhanced_cls, patch_tokens] → [B, 129, 512]
  ↓
输出: RGB_tokens [B, 129, 512], RGB_score [B, num_classes], RGB_global [B, 512]

【NI模态处理路径】 (与RGB相同，modality='nir')
NI [B, 3, 256, 128]
  ↓
build_transformer.forward(NI, modality='nir')
  ↓
(与RGB相同的处理流程)
  ↓
输出: NI_tokens [B, 129, 512], NI_score [B, num_classes], NI_global [B, 512]

【TI模态处理路径】 (与RGB相同，modality='tir')
TI [B, 3, 256, 128]
  ↓
build_transformer.forward(TI, modality='tir')
  ↓
(与RGB相同的处理流程)
  ↓
输出: TI_tokens [B, 129, 512], TI_score [B, num_classes], TI_global [B, 512]

┌─────────────────────────────────────────────────────────────────────────────┐
│                          阶段3: 多模态特征融合                                 │
└─────────────────────────────────────────────────────────────────────────────┘

【数据集类型检测】
is_dual_modal = torch.allclose(NI_global, TI_global, atol=1e-6)
  ↓
├─ True  → RGBNT100 (双模态)
└─ False → RGBNT201 (三模态)

【特征融合策略】

【策略A: 简单拼接 (MAMBA=False)】
  ↓
├─ 双模态: ori = torch.cat([RGB_global, NI_global], dim=-1) → [B, 1024]
└─ 三模态: ori = torch.cat([RGB_global, NI_global, TI_global], dim=-1) → [B, 1536]
  ↓
BNNeck: ori_global = bottleneck(ori) → [B, feat_dim]
  ↓
分类: ori_score = classifier(ori_global) → [B, num_classes]

【策略B: Mamba聚合融合 (MAMBA=True)】
  ↓
AAM模块 (modeling/fusion_part/AAM.py)
  ↓
输入: RGB_cash [B, 129, 512], NI_cash [B, 129, 512], TI_cash [B, 129, 512]
  ↓
Mamba聚合块 (MA Block)
  ├─ 多模态序列交互
  ├─ 状态空间模型处理
  └─ 线性复杂度序列建模
  ↓
特征提取:
  ├─ patch_r = mean(RGB_cash, dim=1) → [B, 512]
  ├─ patch_n = mean(NI_cash, dim=1)  → [B, 512]
  └─ patch_t = mean(TI_cash, dim=1)  → [B, 512]
  ↓
线性降维:
  ├─ r_feature = Linear([cls_r, patch_r]) → [B, 512]
  ├─ n_feature = Linear([cls_n, patch_n]) → [B, 512]
  └─ t_feature = Linear([cls_t, patch_t]) → [B, 512]
  ↓
拼接: fuse = [r_feature, n_feature, t_feature] → [B, 1536]
  ↓
BNNeck: fuse_global = bottleneck_fuse(fuse) → [B, feat_dim]
  ↓
分类: fuse_score = classifier_fuse(fuse_global) → [B, num_classes]


┌─────────────────────────────────────────────────────────────────────────────┐
│                          阶段4: 损失计算与优化                                 │
└─────────────────────────────────────────────────────────────────────────────┘

【训练模式输出】
MambaPro.forward() (training=True)
  ↓
输出格式 (根据direct和mamba配置):
  ├─ direct=True, mamba=True:
  │  └─ [ori_score, ori, fuse_score, fuse]
  │
  ├─ direct=True, mamba=False:
  │  └─ [ori_score, ori]
  │
  ├─ direct=False, mamba=True:
  │  └─ [RGB_score, RGB_global, NI_score, NI_global, TI_score, TI_global, 
  │      fuse_score, fuse]
  │
  └─ direct=False, mamba=False:
     └─ [RGB_score, RGB_global, NI_score, NI_global, TI_score, TI_global]

【损失计算】
engine/processor.py::do_train()
  ↓
损失函数 (layers/make_loss.py::make_loss())
  ├─ ID Loss (分类损失)
  │  └─ CrossEntropyLoss(score, target) 或 LabelSmoothingCrossEntropy
  │
  ├─ Triplet Loss (度量损失)
  │  └─ TripletLoss(feat, target) with margin=0.3
  │
  ├─ Center Loss (可选)
  │  └─ CenterLoss(feat, target)
  │
  └─ MoE Loss (可选)
     ├─ Balance Loss: 专家使用平衡性
     │  └─ 促进各专家使用频率相对均衡
     ├─ Sparsity Loss: 专家激活稀疏性
     │  └─ 促进专家选择的稀疏性，避免过度激活
     └─ Diversity Loss: 专家输出多样性
        └─ 促进专家输出差异化，避免专家退化
     └─ 初始权重引导 (MOE_INIT_WEIGHTS)
        ├─ 训练初期权重分布更接近期望值
        ├─ 加速收敛，减少训练时间
        └─ 平衡专家使用，避免某些专家被忽略
  ↓
总损失: loss = ID_LOSS_WEIGHT × ID_LOSS + 
              TRIPLET_LOSS_WEIGHT × TRI_LOSS + 
              MOE_LOSS (如果启用)

【反向传播与优化】
  ↓
scaler.scale(loss).backward()  # 混合精度反向传播
scaler.step(optimizer)         # 参数更新
scaler.update()                # 缩放因子更新

================================================================================
                          关键技术组件详解
================================================================================

【1. 多尺度滑动窗口】
位置: modeling/fusion_part/clip_multi_scale_sliding_window.py
网络结构:
  ├─ Conv1d层 (滑动窗口)
  │  ├─ kernel_size=4, stride=4  → 4×4窗口
  │  ├─ kernel_size=8, stride=8  → 8×8窗口
  │  └─ kernel_size=16, stride=16 → 16×16窗口
  │
  ├─ AdaptiveAvgPool1d (全局平均池化)
  │  └─ 将窗口特征聚合为单一向量
  │
  └─ MLP融合层
     ├─ Linear(1536 → 512)
     ├─ ReLU
     ├─ Dropout(0.1)
     └─ Linear(512 → 512)

【2. MoE专家网络】
位置: modeling/fusion_part/multi_scale_moe.py
网络结构:
  ├─ 门控网络 (GatingNetwork)
  │  ├─ 初始化阶段:
  │  │  ├─ 初始权重设置 (可选): MOE_INIT_WEIGHTS
  │  │  ├─ 权重归一化: weights = weights / sum(weights)
  │  │  ├─ 转换为logits: logits = log(weights + ε)
  │  │  └─ 设置输出层偏置: gate_output.bias = logits
  │  │     → 引导初始权重分布接近期望值
  │  ├─ 前向传播:
  │  │  ├─ 输入: [B, 1536] (多尺度特征拼接)
  │  │  ├─ MLP: Linear(1536→768) → LayerNorm → GELU → Dropout
  │  │  ├─ MLP: Linear(768→3)
  │  │  ├─ Temperature缩放: scores = scores / temperature
  │  │  └─ Softmax → [B, 3] (专家权重分布)
  │  └─ 作用: 动态计算各专家的权重，实现智能特征融合
  │
  ├─ 专家网络 (ExpertNetwork) × 3
  │  ├─ 专业化分工:
  │  │  ├─ Expert1: 专门处理4×4尺度特征 (细粒度局部细节)
  │  │  ├─ Expert2: 专门处理8×8尺度特征 (中等结构信息)
  │  │  └─ Expert3: 专门处理16×16尺度特征 (全局上下文)
  │  ├─ 网络结构:
  │  │  ├─ 输入: [B, 512] (单个尺度特征)
  │  │  ├─ MLP: Linear(512→hidden_dim) → LayerNorm → GELU → Dropout
  │  │  ├─ MLP: Linear(hidden_dim→512) → LayerNorm → GELU → Dropout
  │  │  ├─ 残差连接: output = expert(x) + residual_proj(x)
  │  │  └─ 输出: [B, 512] (增强后的尺度特征)
  │  └─ 可配置参数:
  │     ├─ MOE_EXPERT_HIDDEN_DIM: 隐藏层维度 (默认1024)
  │     ├─ MOE_EXPERT_LAYERS: 网络层数 (默认2)
  │     ├─ MOE_EXPERT_DROPOUT: Dropout比例 (默认0.1)
  │     └─ MOE_RESIDUAL_WEIGHT: 残差连接权重 (默认1.0)
  │
  └─ 加权融合
     ├─ 权重广播: weight_i → [B, 512] (expand_as)
     ├─ 加权输出: weighted_outputs = [weight_i × expert_i(x_i)]
     ├─ 特征求和: fused_feature = sum(weighted_outputs) → [B, 512]
     └─ 最终融合: Linear + LayerNorm → [B, 512]

【3. Mamba聚合模块 (AAM)】
位置: modeling/fusion_part/AAM.py
网络结构:
  ├─ MA Block (Mamba Aggregation Block) × n_layers
  │  ├─ 状态空间模型 (SSM)
  │  ├─ 选择性扫描机制
  │  └─ 线性复杂度序列建模
  │
  ├─ 特征提取
  │  ├─ patch_r = mean(RGB_tokens, dim=1)
  │  ├─ patch_n = mean(NI_tokens, dim=1)
  │  └─ patch_t = mean(TI_tokens, dim=1)
  │
  └─ 线性降维
     ├─ r_feature = Linear([cls_r, patch_r])
     ├─ n_feature = Linear([cls_n, patch_n])
     └─ t_feature = Linear([cls_t, patch_t])

                          数据维度变化流程

【RGB模态完整流程】
输入图像: [B, 3, 256, 128]
  ↓
CLIP视觉编码器
  ├─ Patch划分: 256×128 → 16×8 = 128 patches
  ├─ Patch Embedding: [B, 128, 512]
  ├─ CLS Token: [B, 1, 512]
  └─ Transformer编码: [B, 129, 512]
  ↓
多尺度滑动窗口 (可选)
  ├─ 分离: cls_token [B, 1, 512], patch_tokens [B, 128, 512]
  ├─ 4×4窗口: [B, 128, 512] → Conv1d → [B, 32, 512] → GAP → [B, 512]
  ├─ 8×8窗口: [B, 128, 512] → Conv1d → [B, 16, 512] → GAP → [B, 512]
  ├─ 16×16窗口: [B, 128, 512] → Conv1d → [B, 8, 512] → GAP → [B, 512]
  ├─ 拼接: [B, 1536]
  ├─ MLP融合: [B, 1536] → [B, 512]
  └─ CLS增强: [B, 1, 512] + [B, 1, 512] → [B, 1, 512]
  ↓
输出: [B, 129, 512] (tokens), [B, 512] (global feature)


================================================================================
                          配置控制流程

【关键配置参数】
configs/RGBNT201/MambaPro.yml
  ├─ MODEL.TRANSFORMER_TYPE: 'ViT-B-16'  # 触发CLIP分支
  ├─ MODEL.USE_CLIP_MULTI_SCALE: True/False  # 多尺度滑动窗口开关
  ├─ MODEL.USE_MULTI_SCALE_MOE: True/False   # MoE融合开关
  ├─ MODEL.MAMBA: True/False                 # Mamba聚合开关
  ├─ MODEL.PROMPT: True                      # Prompt开关（未使用）
  └─ MODEL.ADAPTER: True                     # Adapter开关

【MoE配置参数详解】
  ├─ 基础配置:
  │  ├─ MODEL.MOE_SCALES: [4, 8, 16]  # 滑动窗口尺度列表
  │  ├─ MODEL.MOE_EXPERT_HIDDEN_DIM: 1024  # 专家网络隐藏层维度
  │  └─ MODEL.MOE_TEMPERATURE: 1.0  # 门控网络温度参数
  │
  ├─ 网络结构参数:
  │  ├─ MODEL.MOE_EXPERT_LAYERS: 2  # 专家网络层数
  │  ├─ MODEL.MOE_GATE_LAYERS: 2  # 门控网络层数
  │  ├─ MODEL.MOE_EXPERT_DROPOUT: 0.1  # 专家网络Dropout
  │  └─ MODEL.MOE_GATE_DROPOUT: 0.1  # 门控网络Dropout
  │
  ├─ 融合控制参数:
  │  ├─ MODEL.MOE_EXPERT_THRESHOLD: 0.1  # 专家激活阈值
  │  ├─ MODEL.MOE_RESIDUAL_WEIGHT: 1.0  # 残差连接权重
  │  └─ MODEL.MOE_INIT_WEIGHTS: None  # 专家初始权重 (可选)
  │     ├─ 格式: [0.35, 0.3, 0.35] (长度必须等于专家数量)
  │     ├─ 作用: 引导训练方向，加速收敛，平衡专家使用
  │     └─ 实现: 通过设置门控网络输出层偏置引导初始权重分布
  │
  └─ 损失权重参数 (SOLVER部分):
     ├─ SOLVER.MOE_BALANCE_LOSS_WEIGHT: 0.01  # 专家平衡损失权重
     ├─ SOLVER.MOE_SPARSITY_LOSS_WEIGHT: 0.001  # 稀疏性损失权重
     └─ SOLVER.MOE_DIVERSITY_LOSS_WEIGHT: 0.01  # 多样性损失权重

【分支选择逻辑】
  ├─ TRANSFORMER_TYPE == 'ViT-B-16' → CLIP分支
  ├─ USE_CLIP_MULTI_SCALE == True → 启用多尺度滑动窗口
  ├─ USE_MULTI_SCALE_MOE == True → 启用MoE融合
  │  ├─ 门控网络初始化: 如果设置MOE_INIT_WEIGHTS，则引导初始权重
  │  ├─ 专家网络处理: 每个专家处理对应尺度特征
  │  └─ 动态权重融合: 根据输入内容动态调整专家权重
  └─ MAMBA == True → 启用Mamba聚合融合

【命令行参数使用示例】
./run_experiment.sh \
  --config_file configs/RGBNT201/yzy_best_Mambapro_moe.yml \
  --use_multi_scale --use_moe --disable_attention \
  --opts \
    MODEL.MOE_TEMPERATURE 1.5 \
    MODEL.MOE_EXPERT_HIDDEN_DIM 1024 \
    MODEL.MOE_INIT_WEIGHTS "[0.35,0.3,0.35]" \
    MODEL.MOE_SCALES "[4,8,16]" \
    SOLVER.MOE_BALANCE_LOSS_WEIGHT 0.10

【MOE_INIT_WEIGHTS参数说明】
  ├─ 作用: 设置专家网络的初始权重分布，引导训练方向
  ├─ 格式: 列表，长度必须等于专家数量 (与MOE_SCALES数量一致)
  ├─ 示例: [0.35, 0.3, 0.35] 表示三个专家的初始权重分别为35%、30%、35%
  ├─ 实现原理:
  │  ├─ 将初始权重转换为logits: log(weights)
  │  ├─ 设置门控网络输出层偏置: gate_output.bias = logits
  │  └─ 使得Softmax后的分布接近期望的初始权重
  └─ 效果:
     ├─ 训练初期权重分布更接近期望值
     ├─ 加速收敛，减少训练时间
     ├─ 引导训练方向，基于先验知识
     └─ 平衡专家使用，避免某些专家被忽略
