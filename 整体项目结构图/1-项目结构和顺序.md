# MambaPro 项目结构与执行顺序（2025.12 最新版）

> 目标：以最少的步骤串起 **命令行 → 配置 → 数据 → 模型 → 日志**，确保任何环节都能快速对照代码定位。

---

## 0. 项目鸟瞰

```
CLI (--config_file + --opts)
        ↓
run_experiment.sh        (复制配置 & 注入覆盖项，按需静默)
        ↓
train_net.py             (合并 YAML/命令行 → cfg)
        ↓
utils/config_printer.py  (进入 epoch 前锁定「最终配置」)
        ↓
engine/processor.py      (数据 → 模型 → Loss → Eval → CURRENT/BEST)
        ↓
训练完成统一输出         (Best epoch/mAP/Rank/专家权重)
```

---

## 1. 运行入口与配置合并

| 顺序 | 位置 | 作用 | 备注 |
| --- | --- | --- | --- |
| 1 | `run_experiment.sh` | 解析 `--config_file` 与 `--opts KEY VALUE ...`，复制配置到输出目录并写入覆盖项。默认仅在必要时打印，`CONFIG_PRINTER_ONLY=0` 可恢复调试日志。 | 负责环境准备、日志目录与 Python 启动参数。 |
| 2 | `train_net.py` | `cfg.merge_from_file` + `cfg.merge_from_list` + bool/字符串修正；随后实例化 dataloader、model、optimizer、scheduler、loss。 | 这里也会对 `MODEL.USE_*`、`MODEL.MOE_USE_TOP_K_ROUTING` 等开关做显式布尔化，避免 `"True"` 字符串出错。 |
| 3 | `utils/config_printer.py` | 在训练正式开始前打印「最终配置」。每一项均采用“中文说明 + (CONFIG.KEY) + ✅/❌ + 参数值”的格式，如 `多尺度滑动窗口 (MODEL.USE_CLIP_MULTI_SCALE) = ✅ ENABLED`。 | 只执行一次，便于核对命令行是否生效。 |
| 4 | `engine/processor.py::do_train` | 训练主循环（混合精度 `torch.cuda.amp` + 可选 DDP）。Eval 阶段仅输出两条列表 `[Epoch N] CURRENT ...` / `[Epoch K] BEST ...`，其它描述性日志全部移除。 | 训练结束后统一打印 `Training Finished` 汇总块。 |

**典型命令**

```bash
./run_experiment.sh \
  --config_file configs/RGBNT201/yzy_best_Mambapro_moe.yml \
  --opts \
    MODEL.MOE_USE_TOP_K_ROUTING True \
    MODEL.MOE_TOP_K 2 \
    MODEL.MOE_TOP_K_MODE "soft" \
    SOLVER.MOE_BALANCE_LOSS_WEIGHT 0.001 \
    SOLVER.MOE_DIVERSITY_LOSS_WEIGHT 0.001 \
    OUTPUT_DIR "./outputs/V24.1_Top2_Soft"
```

## 2. 数据与增强链路

| 阶段 | 核心文件 | 关键点 |
| --- | --- | --- |
| 数据集定义 | `data/datasets/RGBNT201.py`、`RGBNT100.py`、`MSVR310.py` | 每条样本返回 `[RGB_path, NI_path, TI_path], pid, camid, viewid`。MSVR310 使用单张拼接图拆分三个模态。 |
| 读取 | `data/datasets/bases.py::read_image` | 统一转为 `RGB`，返回长度为 3 的 PIL 列表；RGBNT100 的虚拟第三模态由 IR 拷贝。 |
| 变换 | `data/datasets/make_dataloader.py` | `train_transforms`：Resize → Flip → Pad → Crop → ToTensor → Normalize。Random Erasing 由 `INPUT.RE_PROB` 驱动，状态会在 config printer 中可见。 |
| Batch | `train_collate_fn` | 将三模态堆叠为 `{'RGB': [B,3,256,128], 'NI': ..., 'TI': ...}`，同时返回 pid/camid/viewid，供后续损失/嵌入使用。 |

## 3. 模型装配（`modeling/make_model.py`）

### 3.1 CLIP Backbone
- 类型由 `MODEL.TRANSFORMER_TYPE` 控制（默认 `ViT-B-16`）。
- 三模态共享权重；支持 `SIE_CAMERA`/`SIE_COE` 摄像机嵌入。
- 输出：`tokens [B,129,512]` + `global [B,512]`。

### 3.2 多尺度滑动窗口（可选）
- 文件：`modeling/fusion_part/clip_multi_scale_sliding_window.py`。
- 开关：`MODEL.USE_CLIP_MULTI_SCALE`，尺度集合 `MODEL.CLIP_MULTI_SCALE_SCALES`（默认 `[4,8,16]`）。
- 每个尺度生成一个 `[B,512]` 特征；下游模块可选择直接拼接或送入 MoE。

### 3.3 预处理融合模块
- **GateFusionConcat**（MLP 门控）：`MODEL.USE_GATE_FUSION`，`MODEL.GATE_DROPOUT` 控制正则；用于在拼接前做轻量门控。
- **AttentionFusionConcat**（真实多头注意力）：`MODEL.USE_ATTENTION_FUSION`，配合 `MODEL.ATTENTION_NUM_HEADS` 与 `MODEL.ATTENTION_DROPOUT`。
- 如果两者均关闭，则采用直接 `torch.cat` 的无预处理模式。

### 3.4 Multi-Scale MoE
- 入口：`modeling/fusion_part/multi_scale_moe.py::CLIPMultiScaleMoE`。
- 组件：
  - `ExpertNetwork` × `len(MOE_SCALES)`：MLP 结构（层数/隐藏维由 `MODEL.MOE_EXPERT_LAYERS` / `MODEL.MOE_EXPERT_HIDDEN_DIM` 控制）。
  - `GatingNetwork`：接收拼接特征 `[B,1536]`，输出 `[B, num_experts]` 权重。
  - `Top-k Routing`：`MODEL.MOE_USE_TOP_K_ROUTING` + `MODEL.MOE_TOP_K` + `MODEL.MOE_TOP_K_MODE (soft/hard)`。软模式保留梯度，硬模式完全屏蔽非 Top-k 专家。
  - `MODEL.MOE_USE_FIXED_WEIGHTS`：可直接指定 `[w1,w2,w3]`，跳过动态门控。
  - `self._latest_expert_weights` 会在前向中更新，供 loss 与日志读取。

### 3.5 融合策略
- **Direct Concat（默认）**：`MODEL.MAMBA=False`。RGB/NI/TI 全局特征直接拼接，经 BNNeck + classifier 输出。
- **Mamba Aggregation Module**：`MODEL.MAMBA=True` → `modeling/fusion_part/AAM.py`。利用状态空间模型对 tokens 做跨模态交互，再输出融合特征。

## 4. 训练 / 验证 / 日志

### 4.1 损失组件（`layers/make_loss.py`）
- ID Loss、Triplet Loss、Center Loss（可选 `MODEL.IF_WITH_CENTER`）。
- MoE Loss（Balance / Sparsity / Diversity）：
  - 静态权重优先由命令行或 YAML 决定。
  - 若 `SOLVER.MOE_USE_DYNAMIC_LOSS_WEIGHT=True`，则根据 epoch 在 `[START, END]` 间插值（线性/余弦可选），但命令行传入 `0.0` 会强制关闭。

### 4.2 优化器（`solver/make_optimizer.py`）
- Backbone / 门控 / 其他参数分别组网，`SOLVER.MOE_GATE_LR_FACTOR` 单独缩放门控网络学习率。
- 支持混合精度：`torch.cuda.amp.GradScaler` 在 `engine/processor.py` 内统一管理。

### 4.3 训练循环（`engine/processor.py::do_train`）
- 核心流程：数据加载 → 模型前向 → 主损失 + MoE Loss → AMP 反传 → 优化器 step → 可选 center loss。
- Eval 阶段（每 `SOLVER.EVAL_PERIOD`）输出两行列表：
  ```
  [Epoch 10] CURRENT -> mAP:78.4 | Rank-1:92.1 | Rank-5:97.0 | Rank-10:98.2 | Experts:[0.34,0.33,0.33]
  [Epoch  8] BEST    -> mAP:78.4 | Rank-1:92.1 | Rank-5:97.0 | Rank-10:98.2 | Experts:[0.34,0.33,0.33]
  ```
  其余说明性日志全部移除，确保终端干净。
- 训练结束统一打印：
  ```
  ========================================
  ✅ Training Finished
     Total Epochs: 60
     Best Epoch: 48
     Best mAP / Rank-1/5/10 …
     🎯 Best Expert Weights: [...]
  ========================================
  ```

## 6. 常见排查路径
1. **配置是否生效？**  
   检查开头 `📋 最终训练配置`，一行一项包含 `(CONFIG.KEY)`、状态与数值。
2. **Top-k / Gate / Attention 开关？**  
   由 config printer 报告；Eval 日志的 `Experts:[w1,w2,w3]` 可确认是否有效。
3. **MoE Loss 权重异常？**  
   命令行设置为 `0.0` 时，`engine/processor.py` 会跳过动态调度并锁定为 0。
4. **终端仍有冗余输出？**  
   确保没有自定义 `print`，调试时使用 `CONFIG_PRINTER_ONLY=0` 查看 shell 细节。

## 7. 关键观察点复盘
1. **命令行**：最终生效的配置由 `--opts` 控制。
2. **配置快照**：`utils/config_printer.py` 提供的唯一真值。
3. **训练日志**：Eval 只看两行 `[CURRENT]` / `[BEST]`。
4. **训练结束**：`✅ Training Finished` 汇总，集中展示最优结果。

掌握以上四个节点即可快速定位任何实验差异所在。**

## 📊 从图像输入到最终输出的完整流程

```
================================================================================
                         MambaPro 完整项目结构流程图
================================================================================

┌─────────────────────────────────────────────────────────────────────────────┐
│                          阶段1: 图像输入与预处理                              │
└─────────────────────────────────────────────────────────────────────────────┘

【输入图像类别】
├─ RGBNT201 (三模态数据集)
│  ├─ RGB图像: 独立文件 [256×128×3]
│  ├─ NIR图像: 独立文件 [256×128×3]  
│  └─ TIR图像: 独立文件 [256×128×3]
│
├─ RGBNT100 (双模态数据集)
│  ├─ RGB图像: 单张图像左半部分 [width/2×height×3]
│  ├─ IR图像:  单张图像右半部分 [width/2×height×3]
│  └─ TI图像:  虚拟（使用IR副本）[width/2×height×3]
│
└─ MSVR310 (三模态拼接数据集)
   └─ 单张拼接图像: [768×128×3]
      ├─ RGB部分: [0:256, 0:128] → 裁剪
      ├─ NI部分:  [256:512, 0:128] → 裁剪
      └─ TI部分:  [512:768, 0:128] → 裁剪

【数据加载流程】
data/datasets/bases.py::read_image()
  ↓
输入: img_path(s) → 图像路径(单个或多个)
  ↓
处理:
  ├─ 单路径 → 切割成RGB/NI/TI (MSVR310)
  ├─ 多路径 → 分别读取 (RGBNT201)
  └─ 单路径重复 → 切割成RGB/IR/虚拟TI (RGBNT100)
  ↓
输出: [RGB图像, NI图像, TI图像] (PIL Image对象列表)

【图像预处理】
data/datasets/make_dataloader.py::train_transforms
  ↓
T.Compose([
  T.Resize([256, 128]),           # 调整尺寸
  T.RandomHorizontalFlip(p=0.5),  # 随机水平翻转
  T.Pad(10),                      # 填充
  T.RandomCrop([256, 128]),       # 随机裁剪
  T.ToTensor(),                   # 转为Tensor [0,1]
  T.Normalize([0.5,0.5,0.5], [0.5,0.5,0.5])  # 归一化到[-1,1]
])
  ↓
输出: [RGB_tensor, NI_tensor, TI_tensor]
     每个: [3, 256, 128] (C×H×W格式)

【Batch组织】
data/datasets/make_dataloader.py::train_collate_fn()
  ↓
输入: batch = [(img_list, pid, camid, viewid), ...]
  ↓
处理:
  ├─ 提取RGB: RGB_list = [img[0] for img in imgs]
  ├─ 提取NI:  NI_list = [img[1] for img in imgs]
  └─ 提取TI:  TI_list = [img[2] for img in imgs]
  ↓
堆叠:
  ├─ RGB = torch.stack(RGB_list) → [B, 3, 256, 128]
  ├─ NI  = torch.stack(NI_list)  → [B, 3, 256, 128]
  └─ TI  = torch.stack(TI_list)   → [B, 3, 256, 128]
  ↓
输出: {
      'RGB': [B, 3, 256, 128],
      'NI':  [B, 3, 256, 128],
      'TI':  [B, 3, 256, 128]
     }
     + pids, camids, viewids


┌─────────────────────────────────────────────────────────────────────────────┐
│                          阶段2: 模型前向传播                                  │
└─────────────────────────────────────────────────────────────────────────────┘

【MambaPro主模型】
modeling/make_model.py::MambaPro.forward()
  ↓
输入: x = {'RGB': [B,3,256,128], 'NI': [B,3,256,128], 'TI': [B,3,256,128]}
     + label, cam_label, view_label
  ↓
┌─────────────────────────────────────────────────────────────────────────────┐
│                    三种模态并行处理 (build_transformer)                       │
└─────────────────────────────────────────────────────────────────────────────┘

【RGB模态处理路径】
RGB [B, 3, 256, 128]
  ↓
build_transformer.forward(RGB, modality='rgb')
  ↓
┌─ CLIP视觉编码器 (self.base)
│  ├─ Patch划分: 256×128 → 16×8 = 128个patches
│  ├─ Patch Embedding: 每个patch → 512维向量
│  ├─ CLS Token: [B, 1, 512]
│  ├─ Position Embedding: 位置编码
│  ├─ SIE Embedding: 相机嵌入 (可选)
│  └─ Transformer编码: 12层Transformer块
│     ↓
│  输出: x = [CLS_token, patch_1, ..., patch_128]
│       形状: [B, 129, 512]
│
├─ 多尺度滑动窗口处理 (可选)
│  ├─ 分离: cls_token [B, 1, 512], patch_tokens [B, 128, 512]
│  │
│  ├─ 多尺度特征提取
│  │  ├─ 4×4窗口: Conv1d(k=4, s=4) → [B, 512, 32] → GAP → [B, 512]
│  │  ├─ 8×8窗口: Conv1d(k=8, s=8) → [B, 512, 16] → GAP → [B, 512]
│  │  └─ 16×16窗口: Conv1d(k=16, s=16) → [B, 512, 8] → GAP → [B, 512]
│  │
│  ├─ 特征拼接: [B, 1536] = [B, 512×3]
│  │  └─ torch.cat([feat_4x4, feat_8x8, feat_16x16], dim=1)
│  │
│  ├─ MLP融合 (传统方式，当 USE_MULTI_SCALE_MOE=False 时使用)
│  │  └─ 实现位置: modeling/fusion_part/clip_multi_scale_sliding_window.py
│  │  └─ 两层MLP结构:
│  │     ├─ Linear(1536→512) + ReLU + Dropout(0.1)
│  │     └─ Linear(512→512)
│  │     → [B, 512] (融合后的单一特征)
│  │  └─ 特点: 简单高效，参数量少，无动态权重学习
│  │
│  └─ 或 MoE融合 (专家网络方式，当 USE_MULTI_SCALE_MOE=True 时使用)
│     │
│     ├─ 分支A: 动态权重融合 (当 MOE_USE_FIXED_WEIGHTS=False 时)
│     │  ├─ 门控网络初始化 (可选)
│     │  │  ├─ 初始权重设置: MOE_INIT_WEIGHTS (如 [0.35, 0.3, 0.35])
│     │  │  ├─ 通过偏置引导: log(weights) → gate_output.bias
│     │  │  └─ 使得初始权重分布接近期望值
│     │  ├─ 门控网络: 计算专家权重 [B, 3]
│     │  │  ├─ 输入: [B, 1536] (多尺度特征拼接)
│     │  │  ├─ MLP处理 → Temperature缩放 → Softmax
│     │  │  └─ 输出: [B, 3] (专家权重分布，随输入动态变化)
│     │  ├─ 专家网络处理:
│     │  │  ├─ Expert1(4×4特征) → [B, 512]
│     │  │  ├─ Expert2(8×8特征) → [B, 512]
│     │  │  └─ Expert3(16×16特征) → [B, 512]
│     │  ├─ 加权融合: Σ(weight_i × expert_output_i) → [B, 512]
│     │  └─ 最终融合层: Linear + LayerNorm → [B, 512]
│     │
│     └─ 分支B: 固定权重融合 (当 MOE_USE_FIXED_WEIGHTS=True 时)
│        ├─ 固定权重设置: MOE_FIXED_WEIGHTS (如 [0.33, 0.33, 0.34])
│        │  ├─ 权重自动归一化: 确保和为1.0
│        │  ├─ 权重数量必须等于专家数量（3个）
│        │  └─ 权重在整个训练过程中保持不变
│        ├─ 门控网络: ❌ 不创建，不参与训练
│        ├─ 专家网络处理:
│        │  ├─ Expert1(4×4特征) → [B, 512]
│        │  ├─ Expert2(8×8特征) → [B, 512]
│        │  └─ Expert3(16×16特征) → [B, 512]
│        ├─ 固定权重融合: Σ(fixed_weight_i × expert_output_i) → [B, 512]
│        │  └─ 权重固定，不随输入变化
│        └─ 最终融合层: Linear + LayerNorm → [B, 512]
│
└─ CLS Token增强
   ├─ enhanced_cls = cls_token + multi_scale_feature.unsqueeze(1)
   └─ 重新组合: x = [enhanced_cls, patch_tokens] → [B, 129, 512]
  ↓
输出: RGB_tokens [B, 129, 512], RGB_score [B, num_classes], RGB_global [B, 512]

【NI模态处理路径】 (与RGB相同，modality='nir')
NI [B, 3, 256, 128]
  ↓
build_transformer.forward(NI, modality='nir')
  ↓
(与RGB相同的处理流程)
  ↓
输出: NI_tokens [B, 129, 512], NI_score [B, num_classes], NI_global [B, 512]

【TI模态处理路径】 (与RGB相同，modality='tir')
TI [B, 3, 256, 128]
  ↓
build_transformer.forward(TI, modality='tir')
  ↓
(与RGB相同的处理流程)
  ↓
输出: TI_tokens [B, 129, 512], TI_score [B, num_classes], TI_global [B, 512]

┌─────────────────────────────────────────────────────────────────────────────┐
│                          阶段3: 多模态特征融合                                 │
└─────────────────────────────────────────────────────────────────────────────┘

【数据集类型检测】
is_dual_modal = torch.allclose(NI_global, TI_global, atol=1e-6)
  ↓
├─ True  → RGBNT100 (双模态)
└─ False → RGBNT201 (三模态)

【特征融合策略】

【策略A: 简单拼接 (MAMBA=False)】
  ↓
├─ 双模态: ori = torch.cat([RGB_global, NI_global], dim=-1) → [B, 1024]
└─ 三模态: ori = torch.cat([RGB_global, NI_global, TI_global], dim=-1) → [B, 1536]
  ↓
BNNeck: ori_global = bottleneck(ori) → [B, feat_dim]
  ↓
分类: ori_score = classifier(ori_global) → [B, num_classes]

【策略B: Mamba聚合融合 (MAMBA=True)】
  ↓
AAM模块 (modeling/fusion_part/AAM.py)
  ↓
输入: RGB_cash [B, 129, 512], NI_cash [B, 129, 512], TI_cash [B, 129, 512]
  ↓
Mamba聚合块 (MA Block)
  ├─ 多模态序列交互
  ├─ 状态空间模型处理
  └─ 线性复杂度序列建模
  ↓
特征提取:
  ├─ patch_r = mean(RGB_cash, dim=1) → [B, 512]
  ├─ patch_n = mean(NI_cash, dim=1)  → [B, 512]
  └─ patch_t = mean(TI_cash, dim=1)  → [B, 512]
  ↓
线性降维:
  ├─ r_feature = Linear([cls_r, patch_r]) → [B, 512]
  ├─ n_feature = Linear([cls_n, patch_n]) → [B, 512]
  └─ t_feature = Linear([cls_t, patch_t]) → [B, 512]
  ↓
拼接: fuse = [r_feature, n_feature, t_feature] → [B, 1536]
  ↓
BNNeck: fuse_global = bottleneck_fuse(fuse) → [B, feat_dim]

分类: fuse_score = classifier_fuse(fuse_global) → [B, num_classes]

     │  └─ 促进专家选择的稀疏性，避免过度激活
     └─ Diversity Loss: 专家输出多样性
        └─ 促进专家输出差异化，避免专家退化

        ├─ 训练初期权重分布更接近期望值
        ├─ 加速收敛，减少训练时间
        └─ 平衡专家使用，避免某些专家被忽略
  ↓
总损失: loss = ID_LOSS_WEIGHT × ID_LOSS + 
              TRIPLET_LOSS_WEIGHT × TRI_LOSS + 
              MOE_LOSS (如果启用)

================================================================================
                          关键技术组件详解
================================================================================

【1. 多尺度滑动窗口】
位置: modeling/fusion_part/clip_multi_scale_sliding_window.py
网络结构:
  ├─ Conv1d层 (滑动窗口)
  │  ├─ kernel_size=4, stride=4  → 4×4窗口
  │  ├─ kernel_size=8, stride=8  → 8×8窗口
  │  └─ kernel_size=16, stride=16 → 16×16窗口
  │
  ├─ AdaptiveAvgPool1d (全局平均池化)
  │  └─ 将窗口特征聚合为单一向量
  │
  └─ MLP融合层
     ├─ Linear(1536 → 512)
     ├─ ReLU
     ├─ Dropout(0.1)
     └─ Linear(512 → 512)

【2. MoE专家网络】
位置: modeling/fusion_part/multi_scale_moe.py
网络结构:
  ├─ 门控网络 (GatingNetwork)
  │  ├─ 初始化阶段:
  │  │  ├─ 初始权重设置 (可选): MOE_INIT_WEIGHTS
  │  │  ├─ 权重归一化: weights = weights / sum(weights)
  │  │  ├─ 转换为logits: logits = log(weights + ε)
  │  │  └─ 设置输出层偏置: gate_output.bias = logits
  │  │     → 引导初始权重分布接近期望值
  │  ├─ 前向传播:
  │  │  ├─ 输入: [B, 1536] (多尺度特征拼接)
  │  │  ├─ MLP: Linear(1536→768) → LayerNorm → GELU → Dropout
  │  │  ├─ MLP: Linear(768→3)
  │  │  ├─ Temperature缩放: scores = scores / temperature
  │  │  └─ Softmax → [B, 3] (专家权重分布)
  │  └─ 作用: 动态计算各专家的权重，实现智能特征融合
  │
  ├─ 专家网络 (ExpertNetwork) × 3
  │  ├─ 专业化分工:
  │  │  ├─ Expert1: 专门处理4×4尺度特征 (细粒度局部细节)
  │  │  ├─ Expert2: 专门处理8×8尺度特征 (中等结构信息)
  │  │  └─ Expert3: 专门处理16×16尺度特征 (全局上下文)
  │  ├─ 网络结构:
  │  │  ├─ 输入: [B, 512] (单个尺度特征)
  │  │  ├─ MLP: Linear(512→hidden_dim) → LayerNorm → GELU → Dropout
  │  │  ├─ MLP: Linear(hidden_dim→512) → LayerNorm → GELU → Dropout
  │  │  ├─ 残差连接: output = expert(x) + residual_proj(x)
  │  │  └─ 输出: [B, 512] (增强后的尺度特征)
  │  └─ 可配置参数:
  │     ├─ MOE_EXPERT_HIDDEN_DIM: 隐藏层维度 (默认1024)
  │     ├─ MOE_EXPERT_LAYERS: 网络层数 (默认2)
  │     ├─ MOE_EXPERT_DROPOUT: Dropout比例 (默认0.1)
  │     └─ MOE_RESIDUAL_WEIGHT: 残差连接权重 (默认1.0)
  │
  └─ 加权融合
     ├─ 权重广播: weight_i → [B, 512] (expand_as)
     ├─ 加权输出: weighted_outputs = [weight_i × expert_i(x_i)]
     ├─ 特征求和: fused_feature = sum(weighted_outputs) → [B, 512]
     └─ 最终融合: Linear + LayerNorm → [B, 512]

【3. Mamba聚合模块 (AAM)】
位置: modeling/fusion_part/AAM.py
网络结构:
  ├─ MA Block (Mamba Aggregation Block) × n_layers
  │  ├─ 状态空间模型 (SSM)
  │  ├─ 选择性扫描机制
  │  └─ 线性复杂度序列建模
  │
  ├─ 特征提取
  │  ├─ patch_r = mean(RGB_tokens, dim=1)
  │  ├─ patch_n = mean(NI_tokens, dim=1)
  │  └─ patch_t = mean(TI_tokens, dim=1)
  │
  └─ 线性降维
     ├─ r_feature = Linear([cls_r, patch_r])
     ├─ n_feature = Linear([cls_n, patch_n])
     └─ t_feature = Linear([cls_t, patch_t])

【MOE_INIT_WEIGHTS参数说明】
  ├─ 作用: 设置专家网络的初始权重分布，引导训练方向
  ├─ 格式: 列表，长度必须等于专家数量 (与MOE_SCALES数量一致)
  ├─ 示例: [0.35, 0.3, 0.35] 表示三个专家的初始权重分别为35%、30%、35%
  ├─ 实现原理:
  │  ├─ 将初始权重转换为logits: log(weights)
  │  ├─ 设置门控网络输出层偏置: gate_output.bias = logits
  │  └─ 使得Softmax后的分布接近期望的初始权重
  └─ 效果:
     ├─ 训练初期权重分布更接近期望值
     ├─ 加速收敛，减少训练时间
     ├─ 引导训练方向，基于先验知识
     └─ 平衡专家使用，避免某些专家被忽略
