```
MultiScaleMoE (主模块)
├── ExpertNetwork (专家网络) × 3
│   ├── Expert1: 处理 4×4 尺度特征
│   ├── Expert2: 处理 8×8 尺度特征

│   └── 计算专家权重分布
└── FinalFusion (最终融合层)
```

## 关键代码

### 1. 门控网络 (GatingNetwork)

**位置**: `modeling/fusion_part/multi_scale_moe.py:152-282`

```python
class GatingNetwork(nn.Module):
    """
    🔥 门控网络模块
    根据输入特征动态计算各专家的权重分布
    """
    
    def __init__(self, input_dim=1536, num_experts=3, temperature=1.0, 
                 dropout=0.1, num_layers=2, init_weights=None):
        super(GatingNetwork, self).__init__()
        self.num_experts = num_experts
        self.temperature = temperature
        
        # 构建MLP门控网络
        layers = []
        current_dim = input_dim
        
        # 隐藏层
        for i in range(num_layers - 1):
            next_dim = current_dim // 2 if i == 0 else current_dim
            layers.extend([
                nn.Linear(current_dim, next_dim),
                nn.LayerNorm(next_dim),
                nn.GELU(),
                nn.Dropout(dropout)
            ])
            current_dim = next_dim
        
        # 输出层（单独创建以便设置初始权重）
        self.gate_output = nn.Linear(current_dim, num_experts)
        layers.append(self.gate_output)
        self.gate = nn.Sequential(*layers)
        
        self._init_weights()
    
    def forward(self, x):
        """
        门控网络前向传播
        
        Args:
            x: [B, input_dim] - 多尺度特征拼接 [B, 1536]
        Returns:
            weights: [B, num_experts] - 专家权重分布 [B, 3]
        """
        # MLP处理
        gate_scores = self.gate(x)  # [B, 3]
        
        # 温度缩放：控制权重分布的尖锐程度
        gate_scores = gate_scores / self.temperature
        
        # Softmax归一化得到权重分布
        weights = F.softmax(gate_scores, dim=-1)  # [B, 3]
        
        return weights
```

**关键逻辑**:
- **输入**: `[B, 1536]` - 3个尺度特征拼接 (512×3)
- **处理**: MLP → 温度缩放 → Softmax
- **输出**: `[B, 3]` - 每个专家的权重 (和为1)

### 2. 专家网络 (ExpertNetwork)

**位置**: `modeling/fusion_part/multi_scale_moe.py:1-150`

```python
class ExpertNetwork(nn.Module):
    """
    🔥 专家网络模块
    每个专家专门处理对应尺度的特征
    """
    
    def __init__(self, input_dim=512, hidden_dim=1024, output_dim=512, 
                 dropout=0.1, num_layers=2):
        super(ExpertNetwork, self).__init__()
        self.input_dim = input_dim
        self.hidden_dim = hidden_dim
        self.output_dim = output_dim
        self.num_layers = num_layers
        
        layers = []
        current_dim = input_dim
        
        # 隐藏层
        for i in range(num_layers - 1):
            layers.append(nn.Linear(current_dim, hidden_dim))
            current_dim = hidden_dim
        
        # 输出层（标准FFN：只有Linear）
        layers.append(nn.Linear(current_dim, output_dim))
        
        self.network = nn.Sequential(*layers)
        self._init_weights()
    
    def forward(self, x):
        """
        专家网络前向传播
        
        Args:
            x: [B, input_dim] - 单个尺度特征 [B, 512]
        Returns:
            output: [B, output_dim] - 专家处理后的特征 [B, 512]
        """
        return self.network(x)
```

**关键逻辑**:
- **输入**: `[B, 512]` - 单个尺度特征
- **处理**: MLP (Linear → Linear)
- **输出**: `[B, 512]` - 专家处理后的特征

### 3. MoE主模块 (MultiScaleMoE)

**位置**: `modeling/fusion_part/multi_scale_moe.py:400-716`

#### 3.1 初始化

```python
class MultiScaleMoE(nn.Module):
    """
    🔥 多尺度Mixture-of-Experts模块
    """
    
    def __init__(self, feat_dim=512, scales=[4, 8, 16], 
                 expert_hidden_dim=1024, temperature=1.0, 
                 expert_dropout=0.1, gate_dropout=0.1, 
                 expert_layers=2, gate_layers=2, init_weights=None):
        super(MultiScaleMoE, self).__init__()
        self.feat_dim = feat_dim
        self.scales = scales
        self.num_experts = len(scales)  # 3
        
        # 🔥 为每个尺度创建专门的专家网络
        self.experts = nn.ModuleList()
        for i, scale in enumerate(scales):
            expert = ExpertNetwork(
                input_dim=feat_dim,      # 512
                hidden_dim=expert_hidden_dim,  # 1024
                output_dim=feat_dim,     # 512
                dropout=expert_dropout,
                num_layers=expert_layers
            )
            self.experts.append(expert)
        
        # 🔥 门控网络：计算专家权重
        gate_input_dim = feat_dim * len(scales)  # 1536
        self.gating_network = GatingNetwork(
            input_dim=gate_input_dim,    # 1536
            num_experts=self.num_experts,  # 3
            temperature=temperature,
            dropout=gate_dropout,
            num_layers=gate_layers,
            init_weights=init_weights
        )
        
        # 🔥 最终融合层
        self.final_fusion = nn.Sequential(
            nn.Linear(feat_dim, feat_dim),
            nn.LayerNorm(feat_dim),
            nn.GELU(),
            nn.Dropout(0.1)
        )
```

#### 3.2 前向传播核心逻辑

```python
def _expert_network_processing(self, multi_scale_features):
    """
    专家网络处理多尺度特征
    
    Args:
        multi_scale_features: List[Tensor] - 多尺度特征列表
                            [4×4特征, 8×8特征, 16×16特征]
                            每个: [B, 512]
    Returns:
        final_feature: [B, 512] - 最终特征
        expert_weights: [B, 3] - 专家权重
    """
    B = multi_scale_features[0].shape[0]
    
    # ========== 步骤1：拼接多尺度特征 ==========
    concat_features = torch.cat(multi_scale_features, dim=1)  
    # [B, 1536] = [B, 512×3]
    
    # ========== 步骤2：门控网络计算专家权重 ==========
    expert_weights = self.gating_network(concat_features)  
    # [B, 3] - 每个专家的权重，和为1
    
    # ========== 步骤3：专家网络处理各尺度特征 ==========
    expert_outputs = []
    for i, (expert, feature) in enumerate(zip(self.experts, multi_scale_features)):
        expert_output = expert(feature)  # [B, 512]
        expert_outputs.append(expert_output)
    # expert_outputs = [
    #     Expert1(4×4特征),   # [B, 512]
    #     Expert2(8×8特征),   # [B, 512]
    #     Expert3(16×16特征)  # [B, 512]
    # ]
    
    # ========== 步骤4：加权融合专家输出 ==========
    weighted_outputs = []
    for i, expert_output in enumerate(expert_outputs):
        weight = expert_weights[:, i:i+1].expand_as(expert_output)  
        # [B, 512] - 将权重扩展到特征维度
        weighted_output = weight * expert_output  # [B, 512]
        weighted_outputs.append(weighted_output)
    
    # 求和得到融合特征
    fused_feature = torch.sum(torch.stack(weighted_outputs, dim=0), dim=0)  
    # [B, 512] = Σ(weight_i × expert_output_i)
    
    # ========== 步骤5：最终融合层 ==========
    final_feature = self.final_fusion(fused_feature)  # [B, 512]
    
    return final_feature, expert_weights
```

## 关键设计点

### 1. 门控网络的作用
- **动态权重计算**: 根据输入特征动态计算每个专家的权重
- **温度参数**: 控制权重分布的尖锐程度
  - 高温度 (T>1): 权重分布更平滑，专家使用更均匀
  - 低温度 (T<1): 权重分布更尖锐，专家使用更集中

### 2. 专家网络的专业化
- **每个专家处理对应尺度**: Expert1→4×4, Expert2→8×8, Expert3→16×16
- **独立参数**: 每个专家有独立的MLP参数，可以学习不同尺度的特征模式

### 3. 加权融合的优势
- **动态选择**: 根据输入内容动态选择重要的专家
- **软路由**: 使用软权重而非硬路由，保持可微性

### 4. 最终融合层
- **特征增强**: 对加权融合后的特征进行进一步处理
- **正则化**: LayerNorm + Dropout 防止过拟合

## 总结

MoE模块的核心思想：
1. **多尺度特征输入**: 3个不同尺度的特征
2. **门控网络**: 动态计算专家权重
3. **专家网络**: 每个专家处理对应尺度特征
4. **加权融合**: 根据权重融合专家输出
5. **最终融合**: 进一步处理融合特征

整个流程保持可微性，支持端到端训练。
