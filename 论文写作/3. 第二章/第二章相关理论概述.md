# 第二章 相关理论概述

## 2.1 跨模态行人重识别基础理论

### 2.1.1 跨模态行人重识别定义

跨模态行人重识别（Cross-modal Person Re-identification）是指在不同成像模态（如RGB、近红外NIR、热红外TIR等）之间进行行人图像匹配和检索的技术。与传统的单模态行人重识别不同，跨模态ReID需要处理不同成像原理导致的显著视觉差异，这增加了特征对齐和匹配的难度。

在数学上，跨模态行人重识别可以形式化为：给定查询图像$I_q$（来自模态$M_q$）和候选图像集合$\{I_g^i\}_{i=1}^N$（来自模态$M_g$），目标是找到与$I_q$属于同一身份的行人图像。这需要学习一个跨模态特征映射函数$f: I \rightarrow \mathbb{R}^d$，使得同一身份的不同模态图像在特征空间中距离较近，而不同身份的图像距离较远。

### 2.1.2 模态差异分析

不同成像模态之间存在显著的物理差异：

**RGB模态**：基于可见光成像，能够捕获丰富的颜色和纹理信息，但在低光照条件下性能下降。

**近红外（NIR）模态**：基于近红外波段成像，能够在夜间或低光照条件下提供较好的图像质量，但缺乏颜色信息。

**热红外（TIR）模态**：基于热辐射成像，能够检测温度差异，在完全黑暗环境下仍能工作，但图像分辨率相对较低。

这些模态差异导致传统的单模态特征提取方法难以直接应用于跨模态场景，需要设计专门的特征对齐和融合策略。

### 2.1.3 评估指标

跨模态行人重识别常用的评估指标包括：

**Rank-k准确率**：检索结果中前k个结果包含目标身份的概率，通常使用Rank-1、Rank-5、Rank-10。

**mAP（mean Average Precision）**：平均精度均值，综合考虑了检索的准确性和完整性。

**CMC曲线**：累积匹配特征曲线，展示不同rank位置上的匹配性能。

## 2.2 多尺度特征学习理论

### 2.2.1 多尺度表示理论

多尺度特征学习是计算机视觉中的基础理论，其核心思想是不同尺度的特征能够捕获不同层次的语义信息。在行人重识别任务中，多尺度特征的重要性体现在：

**局部细节**：小尺度特征能够捕获服装纹理、配饰、边缘等细节信息，这些信息对于区分相似外观的行人具有重要作用。

**中等结构**：中等尺度特征能够捕获身体姿态、动作、形状等结构信息，这些信息反映了行人的基本外观特征。

**全局上下文**：大尺度特征能够捕获整体外观、身材比例、空间布局等全局信息，这些信息提供了行人的整体特征描述。

### 2.2.2 层次化特征理论

层次化特征表示理论认为，视觉特征应该按照从局部到全局的层次结构进行组织。在深度学习中，这种层次化表示通常通过多层网络结构实现：

$$f_l = \sigma(W_l \cdot f_{l-1} + b_l)$$

其中，$f_l$表示第$l$层的特征，$W_l$和$b_l$分别为权重矩阵和偏置向量，$\sigma$为激活函数。

### 2.2.3 滑动窗口理论

滑动窗口是一种经典的特征提取方法，通过固定大小的窗口在输入序列上滑动来提取局部特征。对于一维序列$x = [x_1, x_2, ..., x_n]$，滑动窗口操作可以表示为：

$$y_i = f(x_{i:i+w-1})$$

其中，$w$为窗口大小，$f$为特征提取函数。

## 2.3 Mixture-of-Experts机制理论

### 2.3.1 MoE基本概念

Mixture-of-Experts（MoE）是一种条件计算范式，其核心思想是通过门控网络动态选择最适合的专家网络来处理不同的输入。MoE模型通常包含两个主要组件：

**专家网络（Expert Networks）**：多个专门化的神经网络，每个专家负责处理特定类型的输入。

**门控网络（Gating Network）**：用于计算各专家的权重，决定如何组合专家网络的输出。

### 2.3.2 专业化分工理论

MoE的专业化分工理论认为，不同的专家网络应该专门处理不同类型的输入，从而实现更高效的特征处理。在跨模态行人重识别中，这种专业化分工可以体现在：

**尺度专业化**：不同专家专门处理不同尺度的特征，避免相互干扰。

**模态专业化**：不同专家专门处理不同模态的特征，提高模态适应性。

**任务专业化**：不同专家专门处理不同的子任务，提高整体性能。

### 2.3.3 动态权重分配理论

门控网络通过动态计算专家权重来实现自适应的特征融合：

$$g(x) = \text{softmax}(W_g \cdot x + b_g)$$

$$y = \sum_{i=1}^n g_i(x) \cdot E_i(x)$$

其中，$g(x)$为门控权重，$E_i(x)$为第$i$个专家的输出。

## 2.4 CLIP预训练模型理论

### 2.4.1 对比学习理论

CLIP（Contrastive Language-Image Pre-training）基于对比学习理论，通过最大化正样本对的相似度并最小化负样本对的相似度来学习跨模态表示：

$$\mathcal{L} = -\log \frac{\exp(\text{sim}(I, T) / \tau)}{\sum_{j=1}^N \exp(\text{sim}(I, T_j) / \tau)}$$

其中，$I$和$T$分别为图像和文本特征，$\tau$为温度参数。

### 2.4.2 多模态对齐理论

CLIP通过大规模的多模态数据预训练，学习到了强大的跨模态对齐能力。这种对齐能力体现在：

**语义对齐**：不同模态的语义信息在特征空间中保持一致。

**结构对齐**：不同模态的结构信息能够相互对应。

**层次对齐**：不同模态的特征层次结构保持一致。

### 2.4.3 预训练表示理论

预训练表示理论认为，通过大规模数据预训练获得的表示具有以下优势：

**泛化能力**：预训练表示能够泛化到新的任务和领域。

**表示质量**：预训练表示通常具有更高的质量和更强的表达能力。

**迁移能力**：预训练表示能够有效地迁移到下游任务。

## 2.5 MambaPro框架理论

### 2.5.1 状态空间模型理论

Mamba基于状态空间模型（State Space Model），通过线性时间复杂度的状态更新来建模序列依赖关系：

$$h_t = A h_{t-1} + B x_t$$
$$y_t = C h_t + D x_t$$

其中，$h_t$为隐藏状态，$A$、$B$、$C$、$D$为状态空间参数。

### 2.5.2 选择性扫描理论

Mamba通过选择性扫描机制实现信息的选择性保留和传播：

$$\Delta = \text{Linear}(x)$$
$$B = \text{Linear}(x)$$
$$C = \text{Linear}(x)$$

选择性扫描能够根据输入内容动态调整状态更新策略，提高模型的表达能力。

### 2.5.3 线性复杂度理论

Mamba的线性复杂度优势体现在：

**时间复杂度**：$O(N)$，其中$N$为序列长度。

**空间复杂度**：$O(N)$，相比Transformer的$O(N^2)$有显著优势。

**可扩展性**：能够处理更长的序列，适合高分辨率图像处理。

## 2.6 特征融合理论

### 2.6.1 传统融合方法

**简单拼接**：将不同特征直接拼接，计算简单但缺乏交互。

**加权融合**：通过权重系数组合不同特征，需要手动设计权重。

**注意力融合**：通过注意力机制动态计算融合权重，效果好但计算复杂。

### 2.6.2 动态融合理论

动态融合理论强调根据输入内容自适应调整融合策略：

**内容感知**：根据输入特征的内容特征调整融合策略。

**上下文感知**：考虑输入特征的上下文信息进行融合。

**任务感知**：根据具体任务需求调整融合方式。

### 2.6.3 门控机制理论

门控机制通过门控函数控制信息的流动：

$$g = \sigma(W_g \cdot x + b_g)$$
$$y = g \odot f_1(x) + (1-g) \odot f_2(x)$$

其中，$\odot$为逐元素乘法，$g$为门控权重。
