# 热力图测试脚本使用说明

## 📋 脚本功能

`test_heatmap_from_weight.py` 是一个完整的测试脚本，每次运行可以：

1. ✅ 基于指定的 .pth 权重文件加载模型
2. ✅ **从测试集（test 目录）随机选择 10 张图像**（按人员ID）
3. ✅ 为每个样本生成多模态热力图（RGB/NI/TI）
4. ✅ 进行量化评估（背景抑制、跨模态对齐等）
5. ✅ 自动诊断模型问题并提供改进建议
6. ✅ 生成详细的评估报告（Markdown 格式）

**重要说明**：
- ✅ **所有图像均来自测试集（test 目录），不涉及训练集**
- ✅ 数据集结构: `{dataset_root}/test/RGB/`, `{dataset_root}/test/NI/`, `{dataset_root}/test/TI/`
- ✅ 脚本会自动验证测试集目录是否存在

## 🚀 使用方法

### 基本使用

```bash
cd /home/zhanghaoyang/Desktop/yzy/AboutReid

python test_heatmap_from_weight.py \
    --weight_path /path/to/your_model.pth \
    --config_file configs/RGBNT201/yzy_best_Mambapro_moe.yml \
    --num_images 10
```

### 完整参数示例

```bash
python test_heatmap_from_weight.py \
    --weight_path /home/zhanghaoyang/Desktop/yzy/79.4mAP_1212_1144_run_20251212_112223/MambaProbest.pth \
    --config_file configs/RGBNT201/yzy_best_Mambapro_moe.yml \
    --dataset_root /home/zhanghaoyang/Desktop/yzy/MambaPro/data/datasets/RGBNT201 \
    --num_images 10 \
    --output_dir outputs/Grad_CAM/test_results \
    --alpha 0.4 \
    --seed 42
```

### 参数说明

| 参数 | 必需 | 说明 | 默认值 |
|------|------|------|--------|
| `--weight_path` | ✅ | 模型权重文件路径（.pth） | - |
| `--config_file` | ✅ | 配置文件路径（YAML） | - |
| `--dataset_root` | ❌ | 数据集根目录（**必须包含 test/ 子目录**） | `/home/zhanghaoyang/Desktop/yzy/MambaPro/data/datasets/RGBNT201` |
| `--num_images` | ❌ | 测试图像数量（**从测试集随机选择**的人员ID数量） | `10` |
| `--output_dir` | ❌ | 输出目录 | 自动生成（基于时间戳） |
| `--target_layer` | ❌ | 目标层路径（Grad-CAM） | 自动检测 |
| `--alpha` | ❌ | 热力图透明度（0.0-1.0） | `0.4` |
| `--seed` | ❌ | 随机种子（可复现性） | 随机 |

## 📊 输出结果

脚本会在输出目录生成以下文件：

### 1. 可视化图像
- `heatmap_000123.png` - 人员ID 000123 的多模态热力图
- `heatmap_000456.png` - 人员ID 000456 的多模态热力图
- ...（共 10 张）

每张图像包含：
- 3 行（RGB、NIR、TIR 三种模态）
- 3 列（原始图像、热力图、叠加图像）

### 2. 评估报告
- `evaluation_report.md` - 详细的评估报告（Markdown 格式）

报告内容包括：
- 总体统计（平均对齐度、背景响应等）
- 每个样本的详细评估结果
- 问题诊断和改进建议
- 关键判断标准

### 3. 热力图数据
- `heatmap_data.npz` - 热力图原始数据（NumPy 格式）

可用于后续分析：
```python
import numpy as np
data = np.load('heatmap_data.npz')
heatmap_rgb = data['000123_rgb']
heatmap_ni = data['000123_ni']
heatmap_ti = data['000123_ti']
```

## 📈 评估指标

### 单模态热力图质量

- **人体响应**: 应该 > 0.6
- **背景响应**: 应该 < 0.3
- **抑制比**: 应该 > 2.0
- **聚焦分数**: 应该 > 0.5

### 跨模态对齐度 ⭐ **最重要**

- **对齐分数**: 应该 > 0.8
  - 优秀 (>0.8): ✅ 模型学到了模态不变性特征
  - 一般 (0.5-0.8): ⚠️ 需要进一步优化
  - 较差 (<0.5): ❌ 跨模态对齐失败

## 📝 注意事项

1. **确保路径正确**: 权重文件、配置文件、数据集路径都必须存在
2. **GPU 内存**: 如果 GPU 内存不足，可以减少 `--num_images` 数量
3. **随机性**: 每次运行选择的图像可能不同（除非使用 `--seed`）
4. **时间**: 生成 10 张图像的热力图大约需要几分钟（取决于 GPU）

---

## 🐛 常见问题

### Q1: 找不到目标层
**解决**: 使用 `--target_layer` 手动指定，或检查模型架构

### Q2: 内存不足
**解决**: 减少 `--num_images` 数量，或使用 CPU（但会很慢）

### Q3: 某些模态图像缺失
**解决**: 脚本会自动跳过，确保测试集中三种模态图像都存在
