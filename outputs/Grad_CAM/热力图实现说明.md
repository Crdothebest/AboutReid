# 热力图实现说明

基于《热力图介绍.md》文档，已完成热力图的完整实现。

## 📋 已实现的功能

### 1. 核心实现文件

#### `grad_cam.py` - Grad-CAM 核心实现
- ✅ 自定义 Grad-CAM 实现（使用 PyTorch hooks）
- ✅ 支持 CNN 和 Transformer 架构
- ✅ 热力图生成和叠加功能
- ✅ 目标层自动查找功能

#### `visualize_gradcam.py` - 可视化工具
- ✅ 单张图像可视化
- ✅ 批量图像可视化
- ✅ 多模态可视化（RGB/NI/TI）
- ✅ 命令行接口

#### `heatmap_evaluator.py` - 评估工具 ⭐ **新增**
基于文档实现的量化评估指标：

**核心函数：**
1. **`evaluate_heatmap_quality()`** - 评估单模态热力图质量
   - 人体区域平均响应
   - 背景区域平均响应
   - 抑制比（人体/背景）
   - 聚焦分数（高响应区域集中度）
   - 质量等级评估（优秀/一般/较差）

2. **`evaluate_cross_modal_alignment()`** - 评估跨模态对齐度 ⭐ **最重要**
   - 计算 RGB、NIR、TIR 三种模态热力图的空间对齐度
   - 使用 IoU（交并比）计算两两之间的重叠率
   - 对齐等级评估（优秀/一般/较差）
   - 判断标准：
     - 对齐度 > 0.8：✅ 优秀
     - 对齐度 0.5-0.8：⚠️ 一般
     - 对齐度 < 0.5：❌ 较差

3. **`diagnose_model_issues()`** - 诊断模型问题
   - 自动识别问题类型（背景抑制不足、跨模态对齐失败等）
   - 提供改进建议和代码示例
   - 优先级评估（P0/P1）

4. **`compute_heatmap_alignment()`** - 便捷函数
   - 快速计算对齐度

#### `evaluate_heatmaps.py` - 评估脚本
- ✅ 批量评估热力图
- ✅ 生成评估报告（Markdown 格式）

#### `generate_heatmaps_batch.py` - 批量生成脚本
- ✅ 自动从测试集挑选样本
- ✅ 为多个模型生成热力图
- ✅ 多模态可视化

### 2. 评估热力图

```python
from heatmap_evaluator import (
    evaluate_heatmap_quality,
    evaluate_cross_modal_alignment,
    diagnose_model_issues,
    create_simple_human_mask
)
import numpy as np

# 加载热力图（示例）
heatmap_rgb = np.load('heatmap_rgb.npy')  # 形状: [H, W]
heatmap_nir = np.load('heatmap_nir.npy')
heatmap_tir = np.load('heatmap_tir.npy')

# 创建人体掩码（实际使用时应该使用精确的分割方法）
H, W = heatmap_rgb.shape
human_mask = create_simple_human_mask((H, W))
background_mask = ~human_mask

# 1. 评估单模态质量
metrics_rgb = evaluate_heatmap_quality(heatmap_rgb, human_mask, background_mask)
print(f"RGB 质量: {metrics_rgb['quality_level']}")
print(f"  人体响应: {metrics_rgb['human_response']:.3f} (目标 > 0.6)")
print(f"  背景响应: {metrics_rgb['background_response']:.3f} (目标 < 0.3)")

# 2. 评估跨模态对齐 ⭐ 最重要
alignment = evaluate_cross_modal_alignment(heatmap_rgb, heatmap_nir, heatmap_tir)
print(f"\n跨模态对齐度: {alignment['alignment_score']:.3f}")
print(f"对齐等级: {alignment['alignment_level']}")

# 3. 诊断模型问题
diagnosis = diagnose_model_issues(metrics_rgb, alignment)
print(f"\n{diagnosis['summary']}")
print(f"\n改进建议数量: {len(diagnosis['recommendations'])}")
```

## 📊 评估指标说明

### 单模态热力图质量指标

| 指标 | 目标值 | 说明 |
|------|--------|------|
| **人体响应** | > 0.6 | 人体区域的平均热力图响应值 |
| **背景响应** | < 0.3 | 背景区域的平均热力图响应值 |
| **抑制比** | > 2.0 | 人体响应 / 背景响应 |
| **聚焦分数** | > 0.5 | 高响应区域（>0.7）占人体区域的比例 |

### 跨模态对齐指标 ⭐ **最重要**

| 指标 | 目标值 | 说明 |
|------|--------|------|
| **对齐分数** | > 0.8 | RGB、NIR、TIR 三种模态热力图的空间对齐度 |
| **RGB-NIR IoU** | > 0.8 | RGB 和 NIR 高响应区域的重叠率 |
| **RGB-TIR IoU** | > 0.8 | RGB 和 TIR 高响应区域的重叠率 |
| **NIR-TIR IoU** | > 0.8 | NIR 和 TIR 高响应区域的重叠率 |

**判断标准：**
- **对齐度 > 0.8**：✅ 优秀，模型学到了模态不变性特征
- **对齐度 0.5-0.8**：⚠️ 一般，需要进一步优化
- **对齐度 < 0.5**：❌ 较差，跨模态对齐失败

## 🔍 问题诊断

评估工具会自动诊断以下问题：

### 问题1：背景抑制不足（P0 优先级）
**症状**：背景响应 > 0.5

**改进建议**：
- 增加背景抑制损失函数
- 使用更强的数据增强（背景替换）
- 增加困难负样本挖掘

### 问题2：跨模态对齐失败（P0 优先级）⭐ **最重要**
**症状**：对齐度 < 0.5

**改进建议**：
- 添加跨模态对比学习损失
- 增加模态不变性约束
- 检查 MoE 融合策略，确保不同模态使用相似的专家
- 增加跨模态训练样本

### 问题3：特征提取不充分（P1 优先级）
**症状**：聚焦分数 < 0.3

**改进建议**：
- 检查多尺度特征提取（4x4、8x8、16x16 窗口）
- 增加部分特征损失，鼓励学习身体各部位特征

### 问题4：特征学习不稳定（P1 优先级）
**症状**：人体响应 < 0.4

**改进建议**：
- 检查模型架构和训练策略
- 延长训练时间或增加模型容量

## 📝 使用示例

### 完整评估流程

```python
import numpy as np
from heatmap_evaluator import (
    evaluate_heatmap_quality,
    evaluate_cross_modal_alignment,
    diagnose_model_issues
)

# 1. 加载热力图数据
heatmap_rgb = np.load('heatmap_rgb.npy')
heatmap_nir = np.load('heatmap_nir.npy')
heatmap_tir = np.load('heatmap_tir.npy')

# 2. 创建掩码（实际使用时应该使用精确的分割）
H, W = heatmap_rgb.shape
human_mask = create_simple_human_mask((H, W))
background_mask = ~human_mask

# 3. 评估单模态质量
metrics_rgb = evaluate_heatmap_quality(heatmap_rgb, human_mask, background_mask)
metrics_nir = evaluate_heatmap_quality(heatmap_nir, human_mask, background_mask)
metrics_tir = evaluate_heatmap_quality(heatmap_tir, human_mask, background_mask)

# 4. 评估跨模态对齐 ⭐ 最重要
alignment = evaluate_cross_modal_alignment(heatmap_rgb, heatmap_nir, heatmap_tir)

# 5. 诊断问题
avg_metrics = {
    'human_response': np.mean([m['human_response'] for m in [metrics_rgb, metrics_nir, metrics_tir]]),
    'background_response': np.mean([m['background_response'] for m in [metrics_rgb, metrics_nir, metrics_tir]]),
    'suppression_ratio': np.mean([m['suppression_ratio'] for m in [metrics_rgb, metrics_nir, metrics_tir]]),
    'focus_score': np.mean([m['focus_score'] for m in [metrics_rgb, metrics_nir, metrics_tir]])
}

diagnosis = diagnose_model_issues(avg_metrics, alignment)

# 6. 输出结果
print("="*60)
print("热力图评估结果")
print("="*60)
print(f"\n单模态质量:")
print(f"  RGB: {metrics_rgb['quality_level']}")
print(f"  NIR: {metrics_nir['quality_level']}")
print(f"  TIR: {metrics_tir['quality_level']}")
print(f"\n跨模态对齐: {alignment['alignment_level']} (分数: {alignment['alignment_score']:.3f})")
print(f"\n{diagnosis['summary']}")
```

## 🎯 关键判断标准

基于文档的快速检查清单：

- [ ] **背景响应** < 0.3？
- [ ] **跨模态对齐度** > 0.8？⭐ 最重要
- [ ] **人体响应** > 0.6？
- [ ] **聚焦分数** > 0.5？
- [ ] 三种模态下高亮区域位置是否一致？

**如果以上都满足** → ✅ 模型优秀，可用于论文展示

**如果跨模态对齐失败** → ❌ P0 优先级，立即改进
