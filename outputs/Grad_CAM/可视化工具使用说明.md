# 可视化工具使用说明

## 📋 概述

本项目提供了多种可视化工具，用于分析和展示 ReID 模型的性能：

1. **t-SNE 特征可视化** (`tsne_visualize.py`) - 高维特征降维可视化
2. **检索结果可视化** (`visualize_ranked_list.py`) - Top-K 检索结果展示
3. **模型对比可视化** (`visualize_reid_retrieval.py`) - 新旧模型性能对比
4. **Grad-CAM 热力图可视化** (`visualize_gradcam.py`) - 模型关注区域可视化 ⭐ 新增

## 1. t-SNE 特征可视化

### 功能说明
将高维特征降维到 2D 空间，可视化不同类别（人员ID）的特征分布，评估模型的类内紧凑性和类间可分性。

### 使用步骤

#### 步骤 1: 提取特征
```bash
cd /home/zhanghaoyang/Desktop/yzy/AboutReid

# 使用一键脚本（推荐）
bash run_tsne_from_weight.sh outputs/best_model.pth

# 或手动提取特征
CONFIG_PATH="configs/RGBNT201/yzy_best_Mambapro_moe.yml" \
WEIGHT_PATH="outputs/best_model.pth" \
FEAT_PATH="data/features.npy" \
LABEL_PATH="data/labels.npy" \
python - <<'PY'
# ... 特征提取代码 ...
PY
```

#### 步骤 2: 运行 t-SNE 可视化
```bash
python tsne_visualize.py \
  --features data/features.npy \
  --labels data/labels.npy \
  --perplexity 40 \
  --learning-rate 400 \
  --pca-dims 50 \
  --sample 5000 \
  --output-png outputs/tsne/tsne_result.png \
  --output-csv outputs/tsne/tsne_points.csv
```

### 参数说明
- `--features`: 特征文件路径（必需），支持 .npy 或 .csv
- `--labels`: 标签文件路径（可选），用于颜色编码
- `--perplexity`: t-SNE 困惑度（默认 40），控制近邻数量
- `--learning-rate`: 学习率（默认 400），控制优化步长
- `--pca-dims`: PCA 预降维维度（默认 50），加速计算
- `--sample`: 最大样本数（默认 0），>0 时随机下采样
- `--output-png`: 输出图像路径
- `--output-csv`: 输出坐标 CSV 路径（可选）

## 2. Top-K 检索结果可视化

### 功能说明
生成 ReID 模型的 Top-K 检索结果可视化，展示 Query 图像与 Gallery 图像的相似度排序，用颜色框标注匹配正确性。

### 使用示例

#### 单模态可视化
```bash
python visualzie_rank/visualize_ranked_list.py \
  --config_file configs/RGBNT201/yzy_best_Mambapro_moe.yml \
  --model_path outputs/best_model.pth \
  --dataset_root data/RGBNT201 \
  --modality RGB \
  --top_k 10 \
  --num_queries 10 \
  --output_dir outputs/rank_results
```

#### 多模态可视化
```bash
python visualzie_rank/visualize_ranked_list.py \
  --config_file configs/RGBNT201/yzy_best_Mambapro_moe.yml \
  --model_path outputs/best_model.pth \
  --dataset_root data/RGBNT201 \
  --multimodal \
  --top_k 10 \
  --num_queries 5 \
  --output_dir outputs/rank_results
```

#### 双模型对比
```bash
python visualzie_rank/visualize_ranked_list.py \
  --config_file configs/RGBNT201/yzy_best_Mambapro_moe.yml \
  --model_path outputs/your_model.pth \
  --baseline_model_path outputs/baseline_model.pth \
  --dual_model_mode \
  --dataset_root data/RGBNT201 \
  --modality RGB \
  --top_k 10 \
  --output_dir outputs/rank_comparison
```

### 参数说明
- `--modality`: 模态类型（RGB、NI、TI）
- `--top_k`: Top-K 检索的 K 值
- `--num_queries`: 要可视化的 Query 数量（-1 表示全部）
- `--multimodal`: 启用多模态模式
- `--dual_model_mode`: 双模型对比模式
- `--auto_number`: 自动为输出文件编号（使用时间戳）

## 4. Grad-CAM 热力图可视化 ⭐ 新增

### 功能说明
生成 Grad-CAM 热力图，展示模型在提取特征时关注图像的哪些区域。红色/暖色区域表示高响应（模型关注度高），蓝色/冷色区域表示低响应（模型关注度低）。

### 核心原理
1. **前向传播**：获取目标层的特征图
2. **反向传播**：计算目标输出对特征图的梯度
3. **权重计算**：对梯度进行全局平均池化，得到通道权重
4. **热力图生成**：将权重与特征图加权求和
5. **可视化**：将热力图叠加到原始图像上

### 使用示例

#### 单张图像可视化
```bash
python visualize_gradcam.py \
  --config_file configs/RGBNT201/yzy_best_Mambapro_moe.yml \
  --weight_path outputs/best_model.pth \
  --image_path data/RGBNT201/test/RGB/000123_cam1_0_01.jpg \
  --modality RGB \
  --output_dir outputs/Grad_CAM
```

#### 批量可视化
```bash
python visualize_gradcam.py \
  --config_file configs/RGBNT201/yzy_best_Mambapro_moe.yml \
  --weight_path outputs/best_model.pth \
  --image_dir data/RGBNT201/test/RGB \
  --modality RGB \
  --num_images 20 \
  --output_dir outputs/Grad_CAM
```

#### 多模态可视化
```bash
python visualize_gradcam.py \
  --config_file configs/RGBNT201/yzy_best_Mambapro_moe.yml \
  --weight_path outputs/best_model.pth \
  --query_id 000123 \
  --dataset_root data/RGBNT201 \
  --multimodal \
  --output_dir outputs/Grad_CAM
```

#### 列出可用目标层
```bash
python visualize_gradcam.py \
  --config_file configs/RGBNT201/yzy_best_Mambapro_moe.yml \
  --weight_path outputs/best_model.pth \
  --list_layers \
  --output_dir outputs/Grad_CAM
```

#### 指定目标层
```bash
python visualize_gradcam.py \
  --config_file configs/RGBNT201/yzy_best_Mambapro_moe.yml \
  --weight_path outputs/best_model.pth \
  --image_path data/RGBNT201/test/RGB/000123_cam1_0_01.jpg \
  --target_layer "BACKBONE.image_encoder.transformer.resblocks.11" \
  --output_dir outputs/Grad_CAM
```

### 参数说明
- `--config_file`: 配置文件路径（必需）
- `--weight_path`: 模型权重路径（必需）
- `--output_dir`: 输出目录（必需）
- `--image_path`: 单张图像路径（单张可视化）
- `--image_dir`: 图像目录路径（批量可视化）
- `--query_id`: 查询人员ID（多模态可视化）
- `--modality`: 模态类型（RGB、NI、TI），默认 RGB
- `--multimodal`: 启用多模态模式
- `--num_images`: 批量可视化时的图像数量，默认 10
- `--target_layer`: 目标层路径（自动检测或手动指定）
- `--alpha`: 热力图透明度（0.0-1.0），默认 0.4
- `--list_layers`: 列出所有可用层，然后退出

### 目标层选择指南

#### CLIP ViT-B-16 模型
```python
# 推荐目标层（最后一层 Transformer）
"BACKBONE.image_encoder.transformer.resblocks.11"

# 其他可选层
"BACKBONE.image_encoder.transformer.resblocks.10"  # 倒数第二层
"BACKBONE.image_encoder.transformer.resblocks.9"   # 倒数第三层
```

#### 标准 ViT 模型
```python
"BACKBONE.base.blocks.11"  # 最后一层 Transformer
```

#### ResNet 模型
```python
"BACKBONE.base.layer4"  # 最后一层卷积
```

### 输出说明
- **单张图像**：生成 3 列图像（原始图像、热力图、叠加图像）
- **多模态**：生成 3 行×3 列图像（RGB/NIR/TIR × 原始/热力图/叠加）
- **批量处理**：为每张图像生成单独的可视化文件

## 7. 常见问题

### Q1: t-SNE 计算很慢怎么办？
**A**: 使用 `--sample` 参数进行下采样，或使用 `--pca-dims` 先进行 PCA 降维。

### Q2: Grad-CAM 找不到目标层怎么办？
**A**: 使用 `--list_layers` 参数列出所有可用层，然后手动指定 `--target_layer`。

### Q3: 如何选择合适的 Grad-CAM 目标层？
**A**: 
- CLIP ViT: 使用最后一层 Transformer（`resblocks.11`）
- 标准 ViT: 使用最后一层（`blocks.11`）
- ResNet: 使用最后一层卷积（`layer4`）

### Q4: 热力图显示全红或全蓝怎么办？
**A**: 
- 检查目标层是否正确
- 尝试调整 `--alpha` 参数
- 检查模型是否正常加载
