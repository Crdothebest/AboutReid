Class GradCAM:
    Function __init__(model, target_layer_name):
        self.model = model
        self.model.eval()  # 极其重要：开启评估模式，冻结 BN 和 Dropout
        
        # 定义两个容器，用来暂存数据
        self.gradients = None  # 存放反向传播回来的梯度
        self.activations = None # 存放正向传播时的特征图

        # 注册钩子 (Hooks) - 这是 PyTorch 捕获中间层数据的标准方法
        target_layer = find_layer_by_name(model, target_layer_name)
        
        # 1. 前向传播钩子：记录特征图
        target_layer.register_forward_hook(self.save_activation)
        # 2. 反向传播钩子：记录梯度
        target_layer.register_backward_hook(self.save_gradient)

    Function save_activation(module, input, output):
        self.activations = output  # 这里的 output 就是卷积层的特征图 (C, H, W)

    Function save_gradient(module, grad_input, grad_output):
        self.gradients = grad_output[0] # 这里的 grad_output 就是梯度

    Function generate_heatmap(input_image_tensor, target_class_index = None):
        # 1. 前向传播
        model_output = self.model(input_image_tensor)
        
        # 2. 确定我们要最大化的目标
        IF target_class_index IS None:
            # 如果没指定看哪个人，就默认看预测概率最高的那个人
            target_class_index = argmax(model_output)
            
        # 3. 构造 Loss
        # 我们通过反向传播这个“得分”，来看看谁对这个得分贡献大
        score = model_output[:, target_class_index]
        
        # 4. 反向传播 (关键步骤！)
        self.model.zero_grad()
        score.backward()
        
        # --- 此时，self.gradients 和 self.activations 已经有数据了 ---
        
        # 5. 计算 Grad-CAM 权重 (Global Average Pooling on Gradients)
        # 对梯度的 H 和 W 维度求平均，得到每个通道(Channel)的权重 alpha
        weights = mean(self.gradients, axis=(2, 3)) 
        
        # 6. 加权求和
        # Heatmap = Sum(权重 * 特征图)
        cam = sum(weights * self.activations)
        
        # 7. ReLU 激活
        # 我们只关心正向影响（感兴趣的区域），过滤掉负值
        cam = maximum(cam, 0) 
        
        # 8. 归一化与缩放
        cam = normalize_min_max(cam) # 归一化到 0-1 之间
        cam = resize(cam, (input_image_height, input_image_width)) # 放大回原图尺寸
        
        RETURN cam

第三部分：关键细节说明 (Why this works?)
为什么是 Layer 4？

在 ResNet50 中，layer4 是最后一个卷积层。它包含了最高级的语义信息（这里是人，那里是树），同时还保留了空间信息（人在图中的位置）。如果你选 Layer 1，看到的会是线条和纹理；如果你选全连接层，空间位置就丢失了。

Hook (钩子) 的作用

.pth 文件加载后，模型是一个封闭的计算图。正常运行 model(x) 只会吐出最后的结果。

register_forward_hook 就像在水管中间插了一个水表，用来读取中间流过的水（特征图）。

ReLU 的作用

公式中最后一步是 maximum(cam, 0)。

这是因为我们只关心对识别该身份有正向贡献的像素（让得分变高的区域）。如果某个区域让得分变低了（负值），那说明模型认为那里“肯定不是这个人”，我们在热力图中不需要显示它，所以置为 0。
