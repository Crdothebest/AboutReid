# 第3章 多尺度滑动窗口特征提取方法

## 3.1 研究背景与动机

### 3.1.1 固定尺度特征提取的局限性

传统的跨模态行人重识别方法通常使用固定尺度的特征提取，这种方法存在以下局限性：

**1. 尺度信息丢失：**
- 单一尺度无法捕获不同层次的语义信息
- 局部细节和全局上下文难以兼顾
- 缺乏对多尺度特征的充分利用

**2. 特征表示不充分：**
- 固定窗口大小限制了特征表达能力
- 无法适应不同尺度的目标对象
- 缺乏层次化的特征表示

**3. 鲁棒性不足：**
- 对尺度变化敏感
- 难以处理不同分辨率的输入
- 泛化能力有限

### 3.1.2 多尺度语义信息的重要性

在跨模态行人重识别任务中，多尺度语义信息具有重要作用：

**1. 局部细节信息：**
- 服装纹理、配饰细节
- 面部特征、发型等
- 有助于区分相似行人

**2. 中等结构信息：**
- 身体姿态、动作特征
- 服装样式、颜色分布
- 提供重要的身份线索

**3. 全局上下文信息：**
- 整体外观、身材比例
- 场景背景、环境信息
- 提供全局的身份特征

## 3.2 方法描述

### 3.2.1 整体架构设计

本文提出的多尺度滑动窗口特征提取方法基于CLIP预训练模型，通过多尺度滑动窗口机制提取层次化特征。

**整体架构：**
```
输入图像 → CLIP编码器 → Patch Tokens → 多尺度滑动窗口 → 多尺度特征
```

**核心组件：**
1. **CLIP编码器**：提取基础特征表示
2. **多尺度滑动窗口**：提取不同尺度的特征
3. **特征聚合**：融合多尺度特征信息

### 3.2.2 多尺度滑动窗口机制

**滑动窗口定义：**
对于输入特征序列$X \in \mathbb{R}^{B \times N \times D}$，其中$B$为批次大小，$N$为序列长度，$D$为特征维度，多尺度滑动窗口定义为：

$$W_s = \{X_{:,j:j+s,:} | j = 0, 1, ..., N-s\}$$

其中$s \in \{4, 8, 16\}$为窗口尺度。

**算法1：多尺度特征提取**
```
输入：特征序列 X ∈ R^(B×N×D)，尺度集合 S = {4, 8, 16}
输出：多尺度特征列表 F = {f_s | s ∈ S}

1. for each scale s in S do:
2.     windows = []
3.     for j = 0 to N-s do:
4.         window = X[:, j:j+s, :]
5.         windows.append(window)
6.     windows = stack(windows)  # [B×num_windows×s×D]
7.     f_s = GlobalAveragePool(Extractor_s(windows))
8.     F.append(f_s)
9. return F
```

### 3.2.3 特征提取策略

**1. 局部尺度特征（4×4窗口）：**
- 捕获细粒度纹理信息
- 提取服装细节、配饰特征
- 提供高分辨率的局部信息

**2. 中等尺度特征（8×8窗口）：**
- 捕获结构信息
- 提取身体姿态、动作特征
- 提供中等范围的结构信息

**3. 全局尺度特征（16×16窗口）：**
- 捕获全局上下文信息
- 提取整体外观、身材比例
- 提供全局的语义信息

**特征提取过程：**
```python
def extract_multi_scale_features(patch_tokens, scales=[4, 8, 16]):
    """
    提取多尺度特征
    
    Args:
        patch_tokens: [B, N, D] - CLIP patch tokens
        scales: list - 滑动窗口尺度列表
    
    Returns:
        multi_scale_features: List[Tensor] - 各尺度特征列表
    """
    B, N, D = patch_tokens.shape
    multi_scale_features = []
    
    for scale in scales:
        if N >= scale:
            # 使用1D卷积进行滑动窗口处理
            windowed_feat = sliding_window_conv(patch_tokens, scale)
            # 全局平均池化
            pooled_feat = F.adaptive_avg_pool1d(windowed_feat, 1).squeeze(-1)
        else:
            # 如果序列长度小于窗口大小，直接使用全局平均池化
            pooled_feat = F.adaptive_avg_pool1d(patch_tokens, 1).squeeze(-1)
        
        multi_scale_features.append(pooled_feat)
    
    return multi_scale_features
```

## 3.3 实验结果与分析

### 3.3.1 实验设置

**数据集：** RGBNT201数据集
- RGB模态：可见光图像
- NIR模态：近红外图像  
- TIR模态：热红外图像

**实验配置：**
- 骨干网络：CLIP ViT-B/16
- 输入尺寸：256×128
- 批次大小：32
- 学习率：0.0005
- 训练轮数：60

### 3.3.2 不同尺度组合的对比实验

**实验设计：**
对比不同尺度组合对性能的影响，验证多尺度特征的有效性。

**实验结果：**

| 尺度组合 | mAP | Rank-1 | Rank-5 | 参数量 |
|----------|-----|--------|--------|--------|
| 基线（单尺度） | 85.2% | 92.1% | 97.3% | 86M |
| [4, 8] | 86.9% | 93.6% | 97.8% | 87.2M |
| [4, 8, 16] | **87.8%** | **94.3%** | **98.1%** | 87.8M |
| [4, 8, 16, 32] | 87.5% | 94.1% | 98.0% | 88.4M |

**结果分析：**
1. **三尺度组合最优**：[4, 8, 16]组合在性能和效率之间达到最佳平衡
2. **性能提升显著**：相比基线方法，mAP和Rank-1分别提升2.6%和2.2%
3. **参数量增加有限**：仅增加1.8M参数，计算开销可控
