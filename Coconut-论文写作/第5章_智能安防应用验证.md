### 5.1.2 专家权重分布分析

**专家权重可视化：**
通过分析专家权重分布，验证专家网络的专业化分工效果。

**权重分布特点：**
1. **4×4专家**：在细节丰富的图像中权重较高
2. **8×8专家**：在结构清晰的图像中权重较高
3. **16×16专家**：在全局信息重要的图像中权重较高

**权重分析代码：**
```python
def analyze_expert_weights(expert_weights, scales=[4, 8, 16]):
    """
    分析专家权重分布
    
    Args:
        expert_weights: [B, num_experts] - 专家权重分布
        scales: list - 滑动窗口尺度列表
    """
    with torch.no_grad():
        # 计算每个专家的平均权重
        avg_weights = torch.mean(expert_weights, dim=0)
        
        # 计算每个专家的激活率
        threshold = 0.1
        activation_rates = torch.mean((expert_weights > threshold).float(), dim=0)
        
        print("专家权重分布分析:")
        for i, scale in enumerate(scales):
            print(f"  {scale}x{scale}专家: 平均权重={avg_weights[i]:.4f}, 激活率={activation_rates[i]:.4f}")
        
        return {
            'avg_weights': avg_weights.cpu().numpy(),
            'activation_rates': activation_rates.cpu().numpy(),
            'scale_names': [f'{scale}x{scale}' for scale in scales]
        }
```

### 5.1.3 多尺度特征热力图

**特征热力图可视化：**
通过GradCAM技术生成多尺度特征的热力图，展示模型对不同区域的关注程度。

**热力图生成过程：**
1. **特征提取**：提取多尺度特征表示
2. **梯度计算**：计算特征对最终决策的梯度
3. **热力图生成**：将梯度信息映射到原始图像
4. **可视化展示**：生成不同尺度的热力图

**热力图分析：**
- **4×4尺度**：关注局部细节，如服装纹理、配饰等
- **8×8尺度**：关注中等结构，如身体姿态、动作等
- **16×16尺度**：关注全局信息，如整体外观、身材比例等
