# 第2章 相关理论概述

## 2.1 跨模态行人重识别基础

### 2.1.1 任务定义与挑战

跨模态行人重识别（Cross-Modal Person Re-identification）是指在不同的成像模态之间进行行人匹配的任务。与传统的单模态行人重识别不同，跨模态任务需要处理不同成像模态之间的显著外观差异。

**任务定义：**
给定查询图像（Query）和候选图像库（Gallery），跨模态行人重识别的目标是找到与查询图像属于同一行人的候选图像。查询图像和候选图像可能来自不同的成像模态，如RGB、近红外（NIR）、热红外（TIR）等。

**主要挑战：**
1. **模态差异**：不同成像模态之间存在显著的外观差异
2. **光照变化**：不同时间和环境下的光照条件差异
3. **视角变化**：不同摄像头拍摄角度和距离的差异
4. **遮挡问题**：行人被其他物体遮挡的情况
5. **尺度变化**：不同距离拍摄导致的尺度差异

### 2.1.2 评估指标

跨模态行人重识别使用标准的行人重识别评估指标：

**1. 平均精度均值（mAP, mean Average Precision）**
$$mAP = \frac{1}{Q} \sum_{q=1}^{Q} AP(q)$$

其中$Q$为查询图像数量，$AP(q)$为第$q$个查询的平均精度。

**2. Rank-1准确率**
Rank-1准确率表示正确匹配出现在第一位候选结果中的比例。

**3. Rank-5准确率**
Rank-5准确率表示正确匹配出现在前五位候选结果中的比例。

**4. 累积匹配特性（CMC）**
CMC曲线展示了不同Rank位置上的累积匹配率。

## 2.2 CLIP预训练模型

### 2.2.1 Vision Transformer架构

CLIP（Contrastive Language-Image Pre-training）是OpenAI提出的多模态预训练模型，其视觉编码器基于Vision Transformer（ViT）架构。

**ViT核心组件：**
1. **图像分块（Image Patching）**：将输入图像分割成固定大小的块
2. **位置编码（Positional Encoding）**：为每个块添加位置信息
3. **Transformer编码器**：多层自注意力机制处理序列
4. **分类头**：输出最终的图像表示

**数学表示：**
对于输入图像$I \in \mathbb{R}^{H \times W \times C}$，ViT首先将其分割为$N$个块：
$$x_p = [x_p^1, x_p^2, ..., x_p^N]$$

然后通过Transformer编码器：
$$z_0 = [x_{class}, x_p^1, x_p^2, ..., x_p^N] + E_{pos}$$
$$z_l = \text{MSA}(\text{LN}(z_{l-1})) + z_{l-1}$$
$$z_l = \text{MLP}(\text{LN}(z_l)) + z_l$$

### 2.2.2 多模态预训练机制

CLIP通过对比学习的方式训练多模态模型，学习图像和文本的联合表示空间。

**对比学习目标：**
$$\mathcal{L} = -\frac{1}{N} \sum_{i=1}^{N} \log \frac{\exp(\text{sim}(I_i, T_i) / \tau)}{\sum_{j=1}^{N} \exp(\text{sim}(I_i, T_j) / \tau)}$$

其中$\text{sim}(I_i, T_j)$表示图像$I_i$和文本$T_j$的相似度，$\tau$为温度参数。

## 2.3 Mixture-of-Experts机制

### 2.3.1 条件计算原理

Mixture-of-Experts（MoE）是一种条件计算范式，通过门控网络动态选择专家网络，实现条件计算。

**基本架构：**
$$y = \sum_{i=1}^{n} G(x)_i \cdot E_i(x)$$

其中$G(x)$为门控网络，$E_i(x)$为第$i$个专家网络，$n$为专家数量。

### 2.3.2 门控网络设计

门控网络负责根据输入特征计算各专家的权重分布：

**门控网络结构：**
$$G(x) = \text{Softmax}(\text{Linear}(\text{GELU}(\text{Linear}(x))))$$

**权重归一化：**
$$\sum_{i=1}^{n} G(x)_i = 1, \quad G(x)_i \geq 0$$

### 2.3.3 专家分工策略

MoE的核心思想是让不同的专家网络专门处理不同类型的输入，实现专业化分工。

**专家网络设计：**
每个专家网络$E_i$通常是一个多层感知机（MLP）：
$$E_i(x) = \text{MLP}_i(x) = \text{Linear}(\text{GELU}(\text{Linear}(x)))$$

**专业化优势：**
- 每个专家专注特定类型的输入
- 避免不同专家之间的相互干扰
- 提高整体模型的表达能力

## 2.4 多尺度特征学习

### 2.4.1 滑动窗口机制

滑动窗口是计算机视觉中常用的多尺度特征提取方法，通过不同大小的窗口捕获不同尺度的信息。

**滑动窗口定义：**
对于输入特征序列$X \in \mathbb{R}^{B \times N \times D}$，滑动窗口定义为：
$$W_s = \{X_{:,j:j+s,:} | j = 0, 1, ..., N-s\}$$

其中$s$为窗口大小，$B$为批次大小，$N$为序列长度，$D$为特征维度。

### 2.4.2 层次化特征表示

多尺度特征学习的目标是构建层次化的特征表示，捕获从局部到全局的语义信息。

**尺度层次：**
1. **局部尺度**：捕获细节特征，如纹理、边缘等
2. **中等尺度**：捕获结构特征，如形状、轮廓等
3. **全局尺度**：捕获语义特征，如对象、场景等

**特征融合策略：**
- **早期融合**：在特征提取阶段融合多尺度信息
- **晚期融合**：在特征表示阶段融合多尺度信息
- **多级融合**：在多个层次上融合多尺度信息

### 2.4.3 多尺度特征的优势

多尺度特征学习具有以下优势：

**1. 信息完整性：**
- 不同尺度捕获不同层次的信息
- 避免单一尺度的信息丢失
- 提供更丰富的特征表示

**2. 鲁棒性：**
- 对尺度变化具有鲁棒性
- 适应不同分辨率的输入
- 提高模型的泛化能力

**3. 表达能力：**
- 层次化的特征表示
- 从局部到全局的语义理解
- 更强大的特征表达能力

## 2.5 本章小结

本章介绍了跨模态行人重识别的基础理论，包括任务定义、评估指标、CLIP预训练模型、MoE机制和多尺度特征学习。这些理论为后续章节的方法设计提供了坚实的理论基础。

**关键要点：**
1. 跨模态行人重识别面临模态差异、光照变化等挑战
2. CLIP模型提供了强大的多模态预训练能力
3. MoE机制通过条件计算实现专业化分工
4. 多尺度特征学习能够捕获层次化的语义信息

这些理论基础的结合为本文提出的多尺度MoE特征融合机制提供了理论支撑，使得该方法能够在保持计算效率的同时提升特征表示能力。
