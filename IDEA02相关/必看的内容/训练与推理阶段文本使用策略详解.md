# 训练与推理阶段文本使用策略详解

> 精简版 · 只保留核心逻辑与设计理由

---

## 一句话总结

训练阶段在融合**之后**用文本增强全局特征，目的是教模型学会"三种模态是同一个人"；推理阶段在融合**之前**用文本逐模态校正，目的是让每个模态在退化时得到独立补偿。

---

## 一、训练阶段：全局语义增强

### 做了什么

1. 三种模态（RGB、NIR、TIR）的图像各自通过 CLIP 骨干提取 512 维视觉特征
2. 三路视觉特征通过 AAM 融合为一个 **1536 维的全局融合特征**
3. 三路文本特征（各 512 维）分别通过独立适配器投影到 1536 维，取平均，生成一个**统一的文本调制信号**
4. 调制信号经过 Sigmoid 压缩为 0~1 的门控信号，与融合特征逐维相乘，以 30% 的权重残差加回原始特征
5. 增强后的特征参与 ID 损失和 Triplet 损失的计算

### 为什么在融合之后用

训练的核心目标是让模型学会**跨模态语义一致性**——三种完全不同的视觉观测（颜色、材质、温度）指向同一个身份。

文本天然具备跨模态统一性。无论从哪个光谱观察，"穿白衣服、背黑包的女性"这个语义是通用的。将文本施加于融合后的全局特征上，相当于给模型一个**语义锚点**，迫使三种模态在特征空间中对齐到同一个语义目标。

如果在融合前分别作用于每个模态，三个模态各自被强化了，但缺少"三者应该统一"的约束信号。

### 好处

| 好处 | 说明 |
|------|------|
| **跨模态语义对齐** | 文本作为统一语义锚点，迫使模型在特征空间中对齐三种模态 |
| **选择性增强** | 门控机制只增强与语义相关的维度，不相关的维度几乎不变 |
| **安全保底** | 残差结构保证原始视觉特征 100% 保留，文本只叠加 30% 权重的修正项 |
| **分模态适配器** | 三种模态的文本各自通过独立适配器，保留了模态语义特异性 |

### 类比

训练阶段的文本像是**课堂上的老师**——面对全班同学（融合后的全局特征），统一传授知识（语义信息），目标是让所有学生真正理解知识体系。

## 二、推理阶段：逐模态独立校正

### 做了什么

1. 三种模态的图像各自提取视觉特征（同训练）
2. **不融合**，而是每个模态的视觉特征与其对应的文本特征配对
3. 每对通过 SafeModalGuidance 网络独立校正：分布对齐 → 门控信号生成 → 以 10% 的幅度残差增强
4. 三个模态各自校正完毕后，拼接为 1536 维最终特征，用于检索

### 为什么在融合之前、逐模态地用

推理面对的核心问题是：**不是每个模态的质量都一样好。**

以夜间监控为例：RGB 因光线不足充满噪声（质量差），NIR 借助主动照明尚可（质量中），TIR 不依赖外部光源（质量好）。

如果在融合后处理，RGB 的噪声已经**污染了全局特征**，此时再用文本补救为时已晚。

如果在融合前逐模态处理：
- RGB 质量差 → RGB 文本重点增强颜色相关维度
- NIR 质量尚可 → NIR 文本轻微调整
- TIR 质量好 → TIR 文本几乎不改

三个模态各自根据自己的状况被独立修正，**好的不受差的拖累。**

### 好处

| 好处 | 说明 |
|------|------|
| **模态间互不干扰** | 一个模态退化不会拖累其他模态，实现模态鲁棒性 |
| **语义补偿退化模态** | 视觉看不清的信息，文本提供旁路补偿（如 RGB 看不到颜色，文本"告诉"模型是白色） |
| **极其保守安全** | 增强幅度仅 10%，加上残差结构，即使文本判断失误也不会损害原始特征 |
| **计算轻量** | 仅两层 MLP + Sigmoid，几乎不增加推理延迟 |

### 类比

推理阶段的文本像是**考前十分钟的私教**——每个学生（每个模态）根据自己的薄弱科目（退化维度），由自己的私教（对应文本）做**一对一微调**，力度极轻，每科独立。

## 三、为什么两个阶段必须用不同的策略

| 维度 | 训练阶段 | 推理阶段 |
|------|---------|---------|
| **根本目标** | 建立能力（学习跨模态统一特征空间） | 稳定发挥（对每个样本做准确特征表达） |
| **文本作用时机** | 融合**之后** | 融合**之前** |
| **文本作用对象** | 一个全局融合特征 | 三个独立的模态特征 |
| **增强幅度** | 30%（较大，允许深度调整） | 10%（极小，追求安全） |
| **容错空间** | 大（梯度可以纠错） | 小（一次输出，无反馈） |
| **需要的交互** | 深度跨模态语义统一 | 轻量级逐模态独立校正 |

**核心逻辑**：

- 训练阶段需要跨模态的深度语义交互来建立统一特征空间 → 必须在融合后的全局层面注入文本
- 推理阶段需要对每个模态的质量独立评估和校正 → 必须在融合前的单模态层面施加引导

**如果反过来会怎样？**

- 训练时逐模态引导 → 三个模态各自被强化，但缺少"三者指向同一个人"的统一约束 → 学不好跨模态一致性
- 推理时全局融合后引导 → 退化模态的噪声先污染全局特征再补救 → 为时已晚；且全局注意力增加推理延迟

所以当前设计是一个**阶段化策略**：训练期深度教学，推理期轻量校正。两者配合，实现语义增强最大化和推理风险最小化。
